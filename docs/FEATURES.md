# 栖页 Qiye · 功能范围

版本：v0.2.2　更新：2026-10-12（香港时间）

## 当前产品选择

| 领域 | 本版范围 |
| --- | --- |
| 访问与账号 | 网站公开、免登录；不建设栖页账号体系 |
| 网站图标 | 自动加载目标网站图标、主动智能提取、文字回退；图标模式随桌面同步 |
| 搜索引擎图标 | 主搜索按钮、引擎菜单与设置列表显示真实图标；按模板来源加载，已知搜索子域使用对应主站，支持主动提取，不发送搜索词 |
| 时间与搜索布局 | 常规设置分别控制时间、搜索框是否在滚动时固定；默认开启，秒数与时分同字号 |
| 跨设备同步 | 用户自有 WebDAV；配置、手动同步、页面内自动检查、冲突确认 |
| 壁纸 | 公开 Picsum API 卡片、本地图片/视频、六款渐变及渐变每日轮换、模糊/暗度 |
| 高级工具 | 不做 PDF、OCR、媒体处理或内嵌 AI 工具箱 |
| 实时内容 | 暂不扩展行情、赛事、实时榜单等数据组件；保留已有可选天气与平台入口 |
| 视觉与交互 | 网站与文件夹直接拖动，组件与触屏使用手柄；13 类组件适配浅色/深色/系统主题，保留各自配色 |

上述排除项是本轮产品决定，不列为必须补齐的路线。

## 已有能力与边界

网站支持增删改、撤销、复制、分组、文件夹和跨组移动。鼠标直接拖动网站或文件夹，小组件和触屏通过拖动手柄操作，可以重排卡片、将网站收进文件夹或把项目移到侧栏分组；拖动时按 `Esc` 取消。保留 `E` 快捷键及编辑按钮。网站/文件夹支持四种网格尺寸，组件支持两种，布局按网格排列，不是任意像素定位。

“设置 → 常规”提供“滚动时固定时间”和“滚动时固定搜索框”两个独立开关。默认均开启，关闭后对应区域随页面滚动；旧备份缺失某个设置时仅为该项补上默认值，保留已有布局和关闭选择。秒数与时、分同字号，以更细字重和较淡颜色区分。内容区不再重复当前分组名称，侧栏继续显示名称；页尾保留日常短句，移除并排的“栖页 · 从这里开始”署名。

桌面面板与 13 类小组件共同响应浅色、深色和跟随系统主题。深色主题调整卡片背景、正文、辅助文字、表单控件和状态色，便签、倒数日、专注等组件保留对应的色彩区别。主题设置位于“设置 → 外观”。

网站卡片默认使用对应站点的真实图标，可改用文字模式；原文字、Emoji 和内置图标及配色保留作为回退。不上传自定义图标图片。

自动图标按本机候选、站点常规图标地址、扩展浏览器图标依次尝试，全部失败显示文字。新增或编辑网站时点击“智能提取”，才会读取去除查询参数与片段的页面 HTML，解析 `rel="icon"` / `apple-touch-icon`，必要时补充同源 manifest 的图标；不运行网页脚本。扩展按站点请求权限，网页版读取受 CORS 限制，不使用第三方图标代理。提取仅处理公开 HTTPS 域名；成功候选和图标地址缓存 7 天，最多 200 个页面，提取失败暂避 10 分钟，图片加载失败在当前页面暂避 5 分钟。文字模式不加载远端图标；旧备份缺失模式时使用自动模式并保留原文字。

搜索支持必应、百度、Google、DuckDuckGo、哔哩哔哩及自定义模板。主搜索框的引擎按钮、切换菜单与搜索设置列表复用网站图标的加载和本机缓存，图标请求根据搜索模板的网站来源，不携带搜索词或请求搜索结果页。已知搜索子域（哔哩哔哩的 `https://search.bilibili.com`）使用对应主站 `https://www.bilibili.com/`，其他来源保留原子域。设置列表中可主动点击“提取图标”读取相应站点首页，按扩展站点权限或网页 CORS 策略处理，失败显示图标候选或文字回退。书签导入复制选中网址，不修改浏览器原书签；历史结果只用于当前查询。`Alt+C` 打开新的栖页搜索页面，不在任意网页注入浮层。

便签、待办、习惯、专注和天气分别共用数据；添加同类卡片不会创建独立清单。倒数日、下班设置、摘录和世界时钟可按卡片配置。热点组件提供平台入口，不显示实时排名。

WebDAV 同步整份栖页 JSON，包括桌面、个人组件内容、壁纸、主题、两个固定显示设置 `pinClock` / `pinSearch`、搜索模板及每个网站的 `iconMode`（`auto` / `text`）；网站和引擎图标提取缓存、WebDAV 凭据单独保存在本机，不进入备份或同步。首次不同、双端改动和过期确认不会被静默覆盖；本地多标签页同样具有旧版本写入保护。两者均不提供逐字段自动合并。

目前未适配 Firefox、iTab 私有备份格式或完整浏览器书签管理。当前范围不等于 iTab 全部页面与动效都已一致；实际验收边界见 [QA.md](QA.md)。

参考产品公开介绍：<https://www.itab.link/>。实现细节以随包源码为准，不依赖 iTab 私有接口。
