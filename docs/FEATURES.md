# 栖页 Qiye · 功能范围

版本：v0.3.0　更新：2026-10-12（香港时间）

## 当前产品选择

| 领域 | 本版范围 |
| --- | --- |
| 访问与账号 | 网站公开、免登录；不建设栖页账号或订阅中心，头像只是本地设置入口 |
| 桌面整理 | 网站、组件、分组、文件夹、多尺寸网格、拖动排序、跨分组移动与撤销 |
| 导航 | 左/右侧栏或顶部导航；宽度、透明度、分组名称、始终显示/自动隐藏/收起 |
| 网站图标 | 站点来源的 SVG 或位图、主动智能提取、实际清晰度判断和有限升级；失败保留文字 |
| 搜索 | 内置与自定义引擎、真实引擎图标、本机收藏查找、可选本机最近搜索 |
| 时间与布局 | 时间/日期/搜索分别控制显示，时间与搜索分别滚动固定、调整水平/垂直位置 |
| 主题与材质 | 浅色/深色/跟随系统；纯色、毛玻璃、亚克力和 Mica 风格；本地 Inter 与系统字体 |
| 跨设备同步 | 用户自有 WebDAV；配置、手动同步、页面内自动检查、冲突确认 |
| 壁纸 | 双栏壁纸中心：自定义、官方渐变、Picsum、Commons 许可图片和外部网站入口；参数单独分区 |
| 高级工具 | 不做 PDF、OCR、媒体处理或内嵌 AI 工具箱 |
| 实时内容 | 暂不扩展行情、赛事、实时榜单等数据组件；保留已有可选天气与平台入口 |

上述排除项是已确定的产品范围，不列为必须补齐的路线。界面对照不等于复制参考产品的所有功能、私有接口或素材。

## 设置分类

点击导航中的栖页图标或自定义头像打开设置。设置按操作对象组织：

| 分类 | 可调整内容 |
| --- | --- |
| 打开方式 | 网站、搜索结果是否在新标签页打开；是否记住上次分组；右上工具始终显示/自动隐藏；壁纸按钮显示；快捷键说明 |
| 搜索栏 | 显示与滚动固定；宽度、高度、圆角、透明度；最近搜索开关与清除；默认/自定义搜索引擎及图标提取 |
| 图标 | 网格尺寸、圆角、图标透明度、间距、名称显示/字号/颜色；是否在网格中显示添加按钮 |
| 时间 / 日期 | 时间显示、滚动固定、秒、12 小时制、字号、字重、颜色或跟随主题；月日、星期、农历显示 |
| 主题与材质 | 浅色/深色/跟随系统、主题色、四种材质、面板透明度、模糊强度、减少视觉效果、字体及界面文字比例 |
| 布局 | 极简模式、页底短句、分组动画、内容最大宽度、时间与搜索框的独立位置、恢复默认位置 |
| 侧边栏 | 头像、左/右侧栏或顶部导航、显示方式、侧栏宽度、导航透明度、分组名称与滚轮模式（滚动列表/切换分组） |
| WebDAV 同步 | 连接配置、手动同步、页面内自动检查、版本比较和冲突确认 |
| 备份与恢复 | JSON 导出与恢复、浏览器书签导入、仅重置设置或恢复初始桌面 |
| 关于栖页 | 版本、功能边界、源码和字体许可入口 |

## 导航、头像与工具

新安装默认使用 **50px 左侧栏**，可调范围 40–120px。侧栏不再显示品牌名称，保留可以打开设置的图标。侧栏左右位置、顶部导航及导航透明度可分别设置；分组名称可隐藏，图标随浅深主题调整显示。

导航支持“始终显示”“自动隐藏”和“收起”。自动隐藏支持鼠标移入与键盘聚焦；收起时保留边缘展开按钮。记住上次分组默认开启，关闭后从第一个分组开始。侧栏滚轮默认滚动列表并隐藏轨道；可以显式选择切换分组模式。编辑/拖动时仍可滚动列表。

头像支持 PNG、JPEG、WebP，本机解码并居中裁切为 **256×256 静态图像**。输入文件上限 **4 MiB**，保存图像数据上限 **256 KiB**，可恢复默认图标。头像不连接账号或头像服务，但作为桌面设置进入 JSON 备份及 WebDAV。

右上角的壁纸、编辑、添加、快捷键四个按钮共同支持始终显示或自动隐藏，眼睛按钮可直接切换，壁纸按钮可单独关闭。键盘按钮在悬停或聚焦时说明栖页实际支持的快捷键，触屏也可以打开说明。默认不在网格中放添加卡片；右上角“＋”和桌面空白处右键菜单仍可添加内容，网格添加卡片可在图标设置中重新启用。

## 时间、搜索与桌面排版

新安装的时间默认 **70px、400 字重**，日期基准字号 **14px**，搜索框默认 **600×46px、23px 圆角**，图标名称默认 **12px**。这些是新桌面默认值，升级不覆盖原来保存的字号、网格与偏好。

时间、日期、搜索框可以分别显示或隐藏。`pinClock` 和 `pinSearch` 是独立的滚动固定开关，默认均开启；关闭后对应区域随页面滚动。秒数与时分使用相同字号，字重、颜色也完全一致，普通 HH:MM:SS 分隔。时间支持 12/24 小时制、200–700 字重、自定义颜色或跟随主题；月日、星期和农历分别控制。

时间和搜索框的水平、垂直偏移独立设置。水平偏移按窗口宽度计，窄屏限制在可见区域；垂直偏移改变排版间距，滚动固定后仍使用相应顶部位置。可以恢复默认位置，也可调整桌面内容最大宽度。卡片仍按网格排列，不是自由像素定位。内容区不再重复当前分组名称，页尾保留可关闭的日常短句，没有并排的品牌署名。

网站与搜索结果的打开方式分别保存为 `openNewTab` 和 `searchNewTab`。搜索支持必应、百度、Google、DuckDuckGo、哔哩哔哩及自定义 `{q}` 模板；图标请求不会携带搜索词。书签导入复制选中网址，不修改浏览器原书签；浏览历史查询只用于当前查询，需要按需权限。`Alt+C` 打开新的栖页搜索页面，不在任意网页注入浮层。

“保存最近搜索”**默认关闭**，开启后在当前浏览器最多保存 **20 条去重记录**，搜索框可显示最近项。关闭后停止记录与显示，已有记录可以单独清除。此记录与浏览器历史查询是两个功能；最近搜索使用独立本机存储，不进入 JSON 备份或 WebDAV，开关偏好本身会随桌面保存。

## 拖动与动画

网站支持增删改、撤销、复制、分组、文件夹和跨组移动。鼠标可以直接拖动网站或文件夹，组件可拖动非交互表面，无单独手柄；触屏长按激活、短划动滚动，输入框和按钮正常使用。可把网站拖到文件夹中央收纳，拖到边缘排序，或拖到导航分组进行跨组移动。`Esc` 取消拖动，`E` 或编辑按钮切换编辑模式。

编辑模式下可以拖动分组；左右侧栏按纵向中点排序，顶部导航按水平中点排序，显示对应方向的插入线。列表超出可见区域时，拖动到边缘可以滚动；在顶部导航内拖动不会误触页面的纵向滚动。

切换分组时卡片短暂错峰、由下向上入场。动画可单独关闭，也响应“减少视觉效果”及系统减少动态效果偏好。卡片的输入、数据保存和跨分组拖动逻辑不依赖动画。

网站和文件夹支持 `1×1`、`2×1`、`2×2`、`4×2`；组件支持 `2×2`、`4×2`。改变尺寸仍受网格和可用窗口宽度约束。

## 主题、字体与材质

桌面面板与 **13 类小组件**共同响应浅色、深色和跟随系统主题。背景、正文、辅助文字、输入控件和状态色相应调整，便签、倒数日等组件保留自己的色彩区别。

| 材质 | 方式与边界 |
| --- | --- |
| 纯色 `solid` | 普通着色面板，无背景模糊 |
| 毛玻璃 `glass` | 半透明背景与背景模糊，默认使用 |
| 亚克力 `acrylic` | 磨砂底色、细微纹理及层次 |
| Mica 风格 `mica` | CSS 柔和着色，不使用背景模糊，也不是 Windows 原生 Mica |

侧栏、搜索框、文件夹和弹层使用共同材质，侧栏与搜索框仍能单独调整透明度。模糊强度默认 **14px**，范围 **0–24px**；开启“减少视觉效果”后关闭面板模糊和过渡动画，改用更实的底色。该选项便于降低效果开销，不构成对所有硬件帧率或资源占用的保证。

字体可选择“Inter + 系统中文”或系统字体，界面文字比例可调。Inter 是本地的拉丁可变 WOFF2，约 **71.21 KiB**，不从远端字体服务加载；中文和其他未包含字符使用设备字体。随包保留 OFL 1.1 完整许可，来源和版权见 [THIRD_PARTY.md](THIRD_PARTY.md)。

## 网站与搜索引擎图标

网站卡片默认使用站点真实图标，可改成文字模式；原文字、Emoji、内置图标和配色保留作为回退。导航头像上传与网站卡片图标是两个功能，网站卡片仍采用自动/文字两种模式。

图标候选结合 SVG、声明尺寸、实际加载尺寸、显示区域和屏幕像素比排序。常规候选包括站点 `/favicon.svg`、`/apple-touch-icon.png`、`/favicon.ico`；扩展中的浏览器图标回退也按目标尺寸请求。已有低清图片会保留显示，同时有限地尝试更清晰的来源，最多 3 个升级候选；同一站点相同或更小尺寸的需求有 24 小时冷却。站点原图太小或缺失时仍可能模糊，不能保证所有网站都提供高清图标。

新增或编辑网站时点击“智能提取”，才读取去掉查询参数和片段的页面 HTML，解析 `rel="icon"` / `apple-touch-icon` 等声明，必要时读取同源 Web App Manifest。提取不运行网页脚本，不使用第三方图标代理；扩展按站点请求权限，网页版读取受 CORS 限制。仅处理公开 HTTPS 域名。成功候选和图标地址缓存 7 天，最多 200 个页面，读取失败暂避 10 分钟，当前页面图片加载失败暂避 5 分钟。

搜索引擎按钮、切换菜单与设置列表共用上述机制，以模板的网站来源作为图标站点。哔哩哔哩搜索子域使用已知对应主站，其余来源保留原子域；“提取图标”读取相应首页，不发送搜索词。浅深主题均不再人为给引擎图标加白底或白边，但原始图片自带的背景不会被强行删除或裁掉。

图标的 `auto` / `text` 模式会随桌面同步；候选、清晰度数据和缓存独立保存在本机，不进入备份。没有 HTML 读取权限或 CORS 不允许时，仍可尝试常规图片地址和文字回退。

## 小组件、备份与迁移

保留 13 类日常组件：在线壁纸、天气、日历、便签、待办、倒数日、专注、下班倒计时、每日一句、热搜入口、计算器、习惯和世界时钟。便签、待办、习惯、专注和天气分别共用数据；添加同类卡片不会创建独立清单。倒数日、下班设置、摘录与世界时钟可按卡片配置。热点组件提供平台入口，不显示实时排名。

WebDAV 同步整份桌面 JSON，包括网站、分组、组件内容、壁纸、头像、主题、导航、布局、搜索模板与打开方式。WebDAV 凭据、网站与引擎图标缓存、最近搜索记录不进入同步文件。首次不同、双端改动和过期确认不会被静默覆盖；本地多标签页同样具有旧版本写入保护。两者均不提供逐字段自动合并。

v0.1 / v0.2.x 的桌面与 JSON 备份继续使用 `schemaVersion: 1`。新增字段只在缺失时补齐，已有布局、字号、主题、关闭选择等保留。旧数据缺失独立搜索打开方式时继承原来的 `openNewTab`。备份恢复后，开关会按恢复的设置生效；本机最近搜索和凭据仍留在各自设备上。

目前未适配 Firefox、iTab 私有备份格式或完整浏览器书签管理。当前范围不等于 iTab 所有页面与功能都已一致；实际测试与浏览器验收边界见 [QA.md](QA.md)。

参考产品：[iTab 官方公开界面](https://go.itab.link/)。实现细节以随包源码为准，不依赖其私有接口。


## v0.3.0 行为更新

拖动实时调整 DOM 顺序，其他卡片通过短时 transform 动画让位；仅松手提交，Esc 复原。稳定容器捕获指针避免节点移动丢失手势。可 Alt+方向键排序。

四个右上角按钮整体自动隐藏，移入/聚焦再显示，无围框；眼睛切换按钮只在工具区交互时出现。网站实际图标的容器无额外白底，保留图像自身像素；加载失败才显示原文字回退底色。底部一言固定，主内容可设置隐藏滚动条但仍可滚动。文件夹移出放在右键菜单。

壁纸双栏弹窗和数据源边界见 [WALLPAPERS.md](WALLPAPERS.md)，GPLv3 与开发说明见 [WIDGETS.md](WIDGETS.md)。官方背景仍是栖页六款内置渐变，不是下载来的 iTab 图库。
