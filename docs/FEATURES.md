# 栖页 Qiye · 功能范围

版本：v0.2.1　更新：2026-10-11

## 当前产品选择

| 领域 | 本版范围 |
| --- | --- |
| 访问与账号 | 网站公开、免登录；不建设栖页账号体系 |
| 网站图标 | 自动加载目标网站图标、主动智能提取、文字回退；图标模式随桌面同步 |
| 跨设备同步 | 用户自有 WebDAV；配置、手动同步、页面内自动检查、冲突确认 |
| 壁纸 | 公开 Picsum API 卡片、本地图片/视频、六款渐变及渐变每日轮换、模糊/暗度 |
| 高级工具 | 不做 PDF、OCR、媒体处理或内嵌 AI 工具箱 |
| 实时内容 | 暂不扩展行情、赛事、实时榜单等数据组件；保留已有可选天气与平台入口 |
| 视觉与交互 | 对齐时钟、搜索、侧栏、网格、卡片和弹层细节；保持栖页独立名称、代码与界面图标 |

上述排除项是本轮产品决定，不列为必须补齐的路线。

## 已有能力与边界

网站支持增删改、撤销、复制、分组、文件夹、跨组移动及编辑模式拖拽。网站卡片默认使用对应站点的真实图标，可改用文字模式；原文字、Emoji 和内置图标及配色保留作为回退。网站/文件夹支持四种网格尺寸，组件支持两种。不是任意像素定位，也不上传自定义图标图片。

自动图标按本机候选、站点常规图标地址、扩展浏览器图标依次尝试，全部失败显示文字。新增或编辑网站时点击“智能提取”，才会读取去除查询参数与片段的页面 HTML，解析 `rel="icon"` / `apple-touch-icon`，必要时补充同源 manifest 的图标；不运行网页脚本。扩展按站点请求权限，网页版读取受 CORS 限制，不使用第三方图标代理。提取仅处理公开 HTTPS 域名；成功候选和图标地址缓存 7 天，最多 200 个页面，提取失败暂避 10 分钟，图片加载失败在当前页面暂避 5 分钟。文字模式不加载远端图标；旧备份缺失模式时使用自动模式并保留原文字。

搜索支持必应、百度、Google、DuckDuckGo、哔哩哔哩及自定义模板。书签导入复制选中网址，不修改浏览器原书签；历史结果只用于当前查询。`Alt+C` 打开新的栖页搜索页面，不在任意网页注入浮层。

便签、待办、习惯、专注和天气分别共用数据；添加同类卡片不会创建独立清单。倒数日、下班设置、摘录和世界时钟可按卡片配置。热点组件提供平台入口，不显示实时排名。

WebDAV 同步整份栖页 JSON，包括桌面、个人组件内容、壁纸设置及每个网站的 `iconMode`（`auto` / `text`）；图标提取缓存和 WebDAV 凭据单独保存在本机，不进入备份或同步。首次不同、双端改动和过期确认不会被静默覆盖；本地多标签页同样具有旧版本写入保护。两者均不提供逐字段自动合并。

目前未适配 Firefox、iTab 私有备份格式或完整浏览器书签管理。当前范围不等于 iTab 全部页面与动效都已一致；实际验收边界见 [QA.md](QA.md)。

参考产品公开介绍：<https://www.itab.link/>。实现细节以随包源码为准，不依赖 iTab 私有接口。
