# v0.3.2 验证记录

## 可复现命令

```sh
npm test
python3 scripts/build-pages.py /path/outside/source/qiye-pages
python3 -m pip install playwright==1.56.0
python3 -m playwright install --with-deps chromium
python3 tests/browser-e2e.py --output test-results
```

`browser-e2e.py` 通过后自动运行 `editor-e2e.py`；两者失败均以非零退出。也可单独运行后者定位网站编辑和弹窗问题。

Node 逻辑 / 集成测试 **252 项**。HTTP 模式包含原有 **100 项**桌面检查和 **50 项**图标编辑 / 工作区检查。以 GitHub Actions 的最终状态为通过依据。图片、元数据和 API 使用明确的受控夹具，不把夹具图片当成真实品牌图标，也不证明上游在线服务全部可用。

本机的 `--local-document` 模式已经完成 **99 + 49 项**，使用隔离文档与存储替身，少两项真正 HTTP origin 的刷新保留检查；不能等同于 HTTP / 实际站点验收。正式发布另核对 Pages 字节和无夹具的实际界面。

## 本版重点

- 自动高清选择和显式全量枚举分开：HTML 已存在足够图标时，显式获取仍读同源 Manifest；返回去重的原站候选。
- 成功解码后才能选择，低清图标显示实际 16×16 等尺寸；不虚构高清。明确选择不会被自动升级或全局缓存改写。
- 获取不保存、点选不保存、保存后选定 URL 精确保留；重新编辑当前图正确，取消还原，文字 / 颜色生效，本机上传重新编码。
- 更改网址清空草稿中的旧图像；过期异步读取与表单关闭不能回写；失败仍保留原选择。
- 侧栏默认中性、可选主题强调；严格布尔字段及图像 URL 校验，兼容旧备份，非法字段整份拒绝。
- 设置 / 添加 / 壁纸无独立高标题栏，大标题在左侧导航；390px、520px 双栏仍无内容横向溢出。
- 浅色面板分层；搜索聚焦前后背景、边框颜色、阴影与模糊均无新增变化。
- 壁纸来源说明只在顶部一次；hover 两个操作；预览不写背景、同一弹窗内保留完整作者 / 来源 / 许可，Esc 回图库，选用才写入。

既有流式 / 固定头部、实时拖拽让位、停留合并文件夹、组件尺寸矩阵、滚轮列表 / 切组、WebDAV 和数据并发测试继续保留。

## 验收边界

没有使用用户 WebDAV 凭据，也没有完成 Chrome/Edge 安装版全部授权、Safari/iOS 真机触屏或低功耗设备全量性能矩阵。原站仅有低清图片、反盗链或 CORS 不开放时仍会回退。显式选择的是网站真实提供的图片，不会补出原站没有的细节。Deepin / Wallhaven 仍是已标日期的清单快照。
