# 地图小组件

在「添加 → 日常 → 地图」添加卡片。卡片不请求网络；打开后点击「启用地图」，才按当前视野加载所选地图源。工作台使用紧凑标题栏、地图画布、地点侧栏和可收起的地图源设置；支持五种卡片尺寸、深浅主题、简体中文 / English 与窄屏布局。

## 地区与地图源

| 地区 / 来源 | 默认选择与能力 | 配置 |
| --- | --- | --- |
| 中国大陆 | 优先高德街道地图；未配置时尝试已配置的天地图，否则显示 OpenStreetMap | 高德需要个人 Web 服务 Key |
| 中国香港 | 香港地政总署底图、繁体或英文地名标注；保留官方标志及署名 | 无需 Key |
| 中国澳门 | 优先天地图；未配置时显示 OpenStreetMap | 天地图需要个人 Key |
| 中国台湾 | 通用电子地图、英文图层及 PHOTO2 正射影像 | 无需 Key |
| 天地图 | 街道、卫星影像及相应地名注记 | 个人 Key |
| OpenStreetMap | 全球街道底图，网络可达性由当前网络决定 | 无需 Key |
| 自定义来源 | 最多 8 个独立地图源，可设置名称、URL、署名、坐标系和缩放级别 | 公开 HTTPS 的 256 px Web Mercator XYZ / WMTS 服务 |

地图工具栏随时显示实际使用的来源。在「地图源与偏好」中为四个地区分别选择首选源，工具栏设为「按地区自动选择」后生效。手动选中的来源缺少 Key 或不覆盖当前地区时显示配置提示，不悄悄改用其他地图。地图加载失败可重试或主动切换来源；不自动循环请求不同服务。

只有天地图和台湾地图提供内置影像切换；不支持影像的来源会禁用对应按钮。自定义影像可以作为另一个地图源添加。瓦片模板须包含 `{z}`、`{x}`、`{y}`，可将 WMTS 的 `TILEMATRIX`、`TILECOL`、`TILEROW` 分别写为这些占位符。自定义服务使用其自身许可和访问要求。

## 接入高德

1. 打开 [高德应用管理](https://console.amap.com/dev/key/app)，为自己的应用申请 **Web 服务** 类型的 Key。
2. 打开地图右上角「地图源与偏好」，填入「高德 Web 服务 Key」并保存。
3. 选择中国大陆，并将来源设为高德或地区自动选择。地点侧栏可将「本地地点」改为「高德地点搜索」。

当前使用官方静态地图 API、POI 搜索与 URI 地点链接。静态地图随拖动 / 缩放重新请求当前视野；不加载高德远程 JS SDK，兼容 Manifest V3 的本地脚本策略。静态图最大请求尺寸为 1024 × 1024、最高缩放 17；更大窗口按显示比例适配。它不提供实时路况、3D 地图或工作台内路线计算。跳转高德不需要填写 Key，地图显示与在线地点搜索需要有效 Key 和相应服务权限 / 额度。

这与高德 **Web 端（JS API）** 的 Key / 安全密钥组合不同。栖页不附带公用 Key，不读取他人凭据，也不使用未公开的免 Key 瓦片地址。当前未持有真实高德或天地图 Key，自动化验证使用受控响应；填写自己的 Key 后仍需确认服务开通、额度、来源限制与当前网络可达性。

## 地点、坐标与操作

- 大陆、香港、澳门、台湾快捷按钮分别回到预设城市；内置常用城市和地标支持部分简繁体、英文别名，例如澳门 / 澳門 / Macau、台北 / 臺北 / Taipei。
- 本地搜索涵盖内置地点与已收藏地点，不发送输入内容。也可输入 `经度, 纬度`，并选择 WGS84 或 GCJ-02。
- 高德地点搜索仅在选择该搜索来源并提交后联网；当前面向中国大陆。港澳台可使用内置地点、坐标选点或外部地图；不把有限的内置地点库描述成完整 POI 数据库。
- 拖动平移，滚轮或加减按钮缩放，点击地图选点；地图获得键盘焦点后支持方向键和 `+` / `-`。
- 最多保存 80 个地点，可重复点击收藏按钮移除；复制坐标会同时注明坐标系。在高德中打开选中地点，或使用 Google Maps 的目的地链接打开路线界面。
- 「我的位置」仅在点击后申请浏览器定位许可。结果显示定位精度；拒绝或失败不影响手动搜索。没有后台位置跟踪。
- 视野、选中地点、地区和收藏进入组件数据，可备份和同步。保存失败保留当前页面内草稿，重开地图可重试；刷新前应完成重试。

原始地点明确记录 WGS84 / GCJ-02。大陆地图源之间使用近似显示转换；香港、澳门、台湾的 WGS84 服务不应用大陆偏移。地区识别用于服务选择，采用粗略覆盖范围，不代表行政边界。转换不用于测绘；不支持 BD-09、HK80、自定义投影或任意图块矩阵。底图的地理范围、名称和边界保持服务提供方原始内容。

## 本机设置与联网边界

个人 Key、地区首选来源、自定义地图源单独存储在 `qiye.map.sources.v1`，不写入桌面 JSON 或 WebDAV。另一设备导入引用了自定义源的组件后，需要在该设备重新配置。浏览器扩展按用户操作申请当前来源的主机权限，定位单独使用可选 `geolocation` 权限；未添加默认全站权限。

启用后仅工作台中可见的地图范围会发给所选服务；地图关闭后移除图片和监听，不预取地图，不提供地图离线下载。瓦片使用浏览器正常 HTTP 缓存。OpenStreetMap 网页请求保留 Referer；扩展请求使用标识 Qiye 的 `X-Requested-With`。个人搜索和定位会发送给所选地图服务；外部地图链接只在用户点击时打开。

## 来源和实现取舍（2026-10-15）

- [高德静态地图](https://lbs.amap.com/api/webservice/guide/api/staticmaps)：Web 服务 Key、缩放 1–17、最大 1024 × 1024；工作台采用 3–17 的实用范围。
- [高德 POI 搜索](https://lbs.amap.com/api/webservice/guide/api-advanced/search)、[URI 入门](https://developer.amap.com/api/uri-api/gettingstarted)：搜索返回 GCJ-02；外部地点链接显式标记 `coordinate=gaode` 或 `wgs84`。
- [高德 JS API 准备](https://lbs.amap.com/api/javascript-api-v2/prerequisites)：JS API 需要对应平台 Key 和安全配置；本次选择无需远程脚本的 Web 服务接口。
- [天地图地图服务](https://lbs.tianditu.gov.cn/server/MapService.html)：Web Mercator WMTS，底图和注记分别加载。文档服务器在本次网络环境返回访问限制，Key 端到端调用未验证。
- [香港地政总署 Topographic Map API](https://p1static.csdi.gov.hk/csdi-webpage/apidoc/TopographicMapAPI)、[Map Label API](https://p1static.csdi.gov.hk/csdi-webpage/apidoc/MapLabelAPI)：WGS84 XYZ 图块，香港底图缩放 10–20，保留官方标志与署名。
- [台湾图资服务 WMTS 说明](https://maps.nlsc.gov.tw/S09SOA/pro/Wmts_ajax_main.jsp)：`EMAP` / `EMAP8` / `PHOTO2` 与 `GoogleMapsCompatible/{z}/{y}/{x}`。
- [OpenStreetMap Tile Usage Policy](https://operations.osmfoundation.org/policies/tiles/)：可见署名、正常缓存、应用标识、无批量预取。没有接入公共 Nominatim 地理编码服务。

渲染器为本地轻量实现，不引入在线 SDK 或重写现有组件框架。地图主画布优先，设置按需打开；小卡片仅显示地点和地区入口，背景是装饰图案，不冒充真实地图。交互 / 权限 / 导入校验见 `tests/map.test.mjs` 与 `tests/map-e2e.py`；网络替身测试不代表实际服务 SLA。

验证包括 12 项地图逻辑测试、生产模块与独立预览各 50 项浏览器检查，以及 7 项原生 MV3 检查；合并最新版组件后，全量 465 项单元测试通过。原生检查预授予测试来源，并用替身验证拒绝权限；没有自动点击真实浏览器授权弹窗。允许联网的隔离浏览器已实际加载香港当前视野全部 24 张底图 / 标注瓦片，以及台北全部 12 张底图瓦片，未模拟响应或关闭证书校验。沙箱浏览器的网络拒绝与 Python 证书链错误属于测试环境限制，不能据此断言地图服务不可用；用户仍需以自己网络中的实际结果为准。高德和天地图仍待真实个人 Key 联调。
