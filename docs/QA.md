# v0.3.0 验证记录

## 自动化与可重复验证

`npm test` 运行 230 项 Node.js 逻辑与集成测试，全部通过。覆盖存储冲突、WebDAV 条件写入、头像异步竞态、图标候选排序与清晰度、壁纸来源校验、分页/授权/取消、实时重排的保存边界。

```sh
npm test
python3 scripts/build-preview.py
python3 -m pip install playwright==1.56.0
python3 -m playwright install chromium
python3 tests/browser-e2e.py --output test-results
```

浏览器脚本使用真正的 HTTP 本机服务和 localStorage；会生成检查报告和截图。固定外部图片/API 响应作为测试夹具，以避免网络波动让回归结果失真，不代表测试图片是正式站点的品牌图标。脚本任一断言失败即非零退出，报告记录已完成项目；以 Actions 的最终退出状态为准，不以部分报告当作全部通过。

开发环境另可运行 `--local-document`：把自有构建渲染到隔离文档，并使用存储替身，不需要访问网站。在本轮本地受限环境中，49 项 Chromium 页面检查通过。此模式不宣称完成实际 HTTP origin、重载持久化或在线服务可用性验证。CI 的正常 HTTP 模式另检查真实 localStorage 刷新保留；最终报告在工作流 artifact 中。

## 页面检查范围

- 普通 HH:MM:SS 及相同字号、字重、颜色；头像设置入口与本机上传；44px 右侧栏及界面位置。
- 工具区四个按钮共同隐藏、鼠标重新显示、无包围边框、快捷键悬浮说明。
- 图标加载后的透明容器，不制造白底；桌面无拖动按钮和默认添加卡片。
- 鼠标拖动开始后，松手前已改变 DOM 顺序，而持久数据仍未改；实际 transform 动画存在；松手保存、Esc 恢复、键盘排序。
- 混合尺寸组件直接拖动；文件夹无默认移出按钮、右键菜单可见且不超出窗口。
- 30 个分组可滚动查看，滚轮默认不切组；可选切组模式；隐藏内容滚动条后页面仍可滚动；一言跨分组保持位置。
- 壁纸组件打开左右布局；明确网络授权、Picsum 和 Commons 清单、来源/许可、独立参数、自定义导入入口、外部来源说明。
- 深浅色、520px 窗口和壁纸面板无横向溢出。

## 本轮发现并修复

实时重排需要移动 DOM 节点，若捕获指针的也是被移动节点，浏览器会释放指针捕获，使拖拽中断。现在由稳定网格/导航容器捕获。窗口 blur 监听只处理窗口本身，不把子元素失焦当作离开浏览器。重排节流时保留待处理命中，松手不再突然跳到另一落点。

## 保留的验收边界

没有使用用户真实 WebDAV 地址或凭据，没有完成 Chrome/Edge 安装版全部权限流程、Safari/iOS 触屏真机、所有目标网站的反盗链/CORS 和全量性能设备矩阵。触屏设计为静止长按约 330ms 后拖动，短划动仍滚动；实际手感须在目标设备验收。天气、第三方图库和站点图标可能因网络或授权失败而回退；不得把夹具通过等同于在线服务全部可用。
