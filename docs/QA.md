# v0.3.1 验证记录

## 可复现命令

```sh
npm test
python3 scripts/build-pages.py /path/outside/source/qiye-pages
python3 -m pip install playwright==1.56.0
python3 -m playwright install --with-deps chromium
python3 tests/browser-e2e.py --output test-results
```

本轮 Node 逻辑/集成测试 **244 项通过**。浏览器脚本的正常 HTTP 模式包含 **100 项检查**，使用本机 HTTP 与真实 localStorage；以 Actions 最终退出状态及报告为准。`--local-document` 是隔离文档/存储替身模式，其中此前的 **93 项**已在本地完成，新增的 6 项大字号多格图标边界以 HTTP CI 验证，不包含 HTTP 重载持久化那一项。不能把此模式等同于真实网站验证。

API、图片等外部响应在回归脚本中使用可重复夹具；绿色测试图不是品牌实际图像，也不证明外部服务可访问。公开站点另以无夹具的检查核验首页字节、真实图标自然尺寸、主题和弹窗，并保存实际截图。

## 本次新增检查

- 时间与搜索默认流式布局，滚动后完全上移；不出现 is-stuck、重边框或压缩。
- 双固定、仅固定时间、仅固定搜索三种组合；固定区域真实占用布局，滚动容器在其下方裁切，不能命中桌面卡片。
- 520×600、小屏顶部导航、160px 时钟与极端偏移，仍保留可读的内容滚动空间。
- 网站拖到另一网站中心，约 500ms 显示合并反馈，松手只创建一个文件夹并一次保存两子项；短暂经过不合并；Esc 恢复并清除提示。
- 选中分组的正方形包含图标和名称；网站图标正方形尺寸、不透明度、圆角控制；独立侧栏图标入口。
- 添加面板左导航/右表单，13 组件目录、网站/文件夹分类表单。
- 全部 13 组件在图标尺寸 48/74/120 下，2×2 框保持正方形、圆角独立，不产生脚本异常。
- 20px 大名称与 2×2/4×2 网站、文件夹组合，在 48/74/120 图标尺寸下仍为正方形外框，不被名称区域挤扁。
- Deepin/Wallhaven 可信清单往返、伪造来源拒绝；面板无外链占位项或组标题。
- 原生 ICO 目录解析、最近足够尺寸、256 哨兵、PNG/DIB 帧、错误长度/越界拒绝。
- 自动补充 metadata 不请求权限，关闭开关不读 head；离开分组的旧回包忽略；已有好图不被低清候选覆盖。
- 大正文的 head 读取提前取消，仍保留正确的 CDN 声明。

既有 WebDAV、数据并发/旧备份、头像、时间、计算器、拖拽保存边界、触屏逻辑及主题回归保留。

## 公开来源核验

2026-10-12 对官方 head / Manifest / 图像自然尺寸进行独立审计。Deepin 官方许可范围及固定提交、Wallhaven API 响应与 CORS 响应头、常用首方图标来源见 [SOURCE-AUDIT.json](SOURCE-AUDIT.json)。HTTP 图片成功与声明解析成功分开记录；失败、403、只得到小尺寸图标均不算高清验证通过。

## 边界

未使用用户 WebDAV 凭据，未完成 Chrome/Edge 安装版全部授权流程、iOS/Safari 触屏真机或低功耗设备性能矩阵。静态站点受原站 CORS、限流、反盗链和网络条件限制；Wallhaven 为注明日期的精选快照而非实时榜单。没有通过 CSS 放大承诺所有网站高清，也未全面重制每个小组件。
