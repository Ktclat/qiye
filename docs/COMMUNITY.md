# 社区组件与桌面分享

> **v0.10.0 仓库拆分：** 主程序不附带组件实现。官方源预置但默认关闭；在设置中启用后添加组件。旧实例与数据保留。组件开发和发布转至 [qiye-widgets](https://github.com/Ktclat/qiye-widgets)，当前契约见 [宿主 API](PLUGIN-API.md)。

[文档索引](README.md) · [中文技术文档](wiki/Community-Widgets.md) · [English technical guide](wiki/Community-Widgets-en.md)

当前入口为 **设置 → 组件源**、**添加 → 小组件** 和 **添加 → 分享与导入**。扩展、独立 HTML 与 GitHub Pages 使用同一套宿主实现。

## 使用社区组件

1. “组件源”总览只显示来源名称、地址、启用状态和数量，支持订阅、停用、移除。官方地址 `https://ktclat.github.io/qiye-widgets/index.json` 内置但默认关闭；启用只读取目录。
2. 点击来源的“查看组件详情”查看该来源的组件、作者、版本、权限、许可证、源码和已添加数量；检查更新与显式更新已添加组件都在这里。
3. “预览与添加”进入添加窗口，也可以从桌面的添加入口进入。分类提供全部、官方源、社区源以及每个已启用自定义来源的名称。搜索、目标分组和窗口控制保留在 46px 标题栏。
4. 用尺寸按钮或左右箭头查看清单所支持的实际卡片尺寸，按当前预览尺寸添加。优先显示该尺寸的作者预览图，缺失或加载失败时使用隔离的实时卡片。连续添加不会清空搜索、尺寸选择或滚动位置。
5. 来源保存在独立本机记录 `qiye.community.v1`，最多订阅 20 个自定义来源，另有一个官方源。不加入桌面备份或 WebDAV。刷新失败保留上次成功目录。
6. 刷新来源只更新目录。点击“更新已添加的组件”才替换同一来源、同一 ID 的已安装清单，保留实例数据；不支持的新尺寸回到 2×2。其他来源不能凭同名 ID 更新已有实例。

只有已启用来源的可见预览会请求作者图片或网页；离开可视区域、筛选隐藏或关闭窗口会回收预览。实时预览收到空实例数据与空存储，宿主拒绝保存、导航、窗口、书签、定位与壁纸调用。预览卡片不接受交互；添加后的组件按正常 API 运行。读取来源不发送登录凭据或 Referer，不接受重定向；扩展按用户操作申请自定义来源域名权限。网页版需要服务允许 CORS。第三方网页仍可自主联网，其内容与可用性由作者负责。

## 桌面排布分享 v1

“分享与导入”可导出选定分组与其中的网站、文件夹、组件尺寸和顺序，格式为 `qiye-layout` / `version: 1`，最大 2 MiB。可选携带白名单中的外观设置，不带自定义壁纸媒体、头像、搜索记录、WebDAV 配置等个人记录。

内置组件恢复默认标题和设置，所有组件内容清空；社区组件保留来源和清单用于安装，但清空实例数据。天气与社区组件不会因导入自动联网运行。网站名称、完整网址及网站图标属于主动分享的内容；发布前应在预览中检查网址是否含私人查询参数或内部地址。

下载的文件可自行放到公开仓库或网站。输入该 JSON 的直达 HTTPS 地址可生成 `https://ktclat.github.io/qiye/#import=编码后的JSON地址`；接收者打开链接时只填写预览表单，不自动请求或导入。扩展中也能粘贴此分享链接。不能公开托管时，直接发送 JSON 文件即可。

导入先校验，再预览、选择分组、选择“新建分组”或“合并到现有分组”。默认跳过桌面已有的相同网址，新建 ID 并重写文件夹关联，单次保存，不覆盖现有内容。导入后在当前页面可撤销；如果此后桌面发生其他修改，拒绝撤销以免覆盖新操作。完整个人备份仍使用设置中的备份功能，与公开排布分享分开。

## 维护与验证

- 清单、来源、实例数据：`src/community-format.js`；联网读取：`src/public-json.js`。
- 目录 UI：`src/community-ui.js`；隔离运行：`src/plugin-host.js`。
- 排布协议：`src/layout-sharing.js`；导入导出：`src/sharing-ui.js`。
- `tests/sharing-community.test.mjs` 检查字段、大小限制、隐私边界、重复网址与 ID 重映射。
- `tests/component-gallery-e2e.py` 验证来源详情、多个来源、五种预览尺寸、连续添加、深浅主题、窄屏、圆角及慢加载过渡；`tests/plugin-e2e.py` 检查持久化和旧数据迁移。线上验证使用 `scripts/verify-live.py`。

主程序构建独立预览并部署公开网页版；组件库单独发布固定版本网页和运行资源。组件就绪前显示当前主题的加载界面，超时提供重试。第三方服务拒绝跨域或嵌入时显示错误，不降级为宿主内执行远程代码。
