# 国际化开发 / Internationalization

栖页当前支持 **简体中文 (`zh-CN`)** 与 **English (`en`)**。默认 `auto` 使用浏览器的首选语言：中文语言族使用简体中文，其余未支持语言使用英语。没有浏览器语言信息的工具环境默认中文。设置 → 打开方式 → 语言 / Language 可立即切换，选择保存在当前桌面并进入 JSON / WebDAV。

The extension and the web app share the same translation module. Choose **Settings → Opening behavior → Language** to override the browser language. Your own group names, card titles, notes and calendar events stay unchanged. A new desktop uses translated sample content; switching language does not rewrite saved content.

## 文件分工

| 文件 | 职责 |
| --- | --- |
| `src/i18n.js` | 支持语言、浏览器匹配、当前语言、`t`、Intl 日期 / 数字与静态 DOM 标记 |
| `src/messages-en.js` | 英文消息目录；中文源文案即消息键，无需复制一份中文 JSON |
| `src/app.js` / `popup.js` | 读取设置、应用语言、重新渲染界面；popup 与主页面共用偏好 |
| `background.js` | 按桌面语言创建收藏右键菜单，语言变更时更新 |
| `_locales/en/messages.json` / `_locales/zh_CN/messages.json` | 浏览器扩展名称、描述、按钮标题及命令说明；由浏览器自身语言选择 |

浏览器管理页的扩展元数据由 Chrome / Edge 决定，页面内语言选项不能更改浏览器界面语言。运行时不请求外部翻译服务，无 i18n 运行时依赖。

## 新增界面文案

```js
import { t, formatDate, formatNumber } from './i18n.js';

button.textContent = t('查看全部 {count} 条', { count: entries.length });
label.textContent = formatDate(new Date(), { dateStyle: 'long' });
amount.textContent = formatNumber(1234.5, { maximumFractionDigits: 1 });
```

1. 使用完整句子作为消息键，不把句子拆成数个翻译片段。当前目录中的 `{v0}` 等为已有模板占位符，新增文案优先使用 `{count}`、`{name}` 等语义名称。
2. 在 `messages-en.js` 添加对应英文，完整保留占位符；数量可以提供 `{ one: '...', other: '...' }`，选择规则来自 `Intl.PluralRules` 的 `count`。
3. `t` 只替换一次，不递归解释插入的值。`t` 不负责 HTML 转义；使用 `textContent`，或者在 HTML 模板的边界对动态内容使用 `escapeHtml` / `escapeText`。URL 必须单独校验。
4. 不在模块顶层计算需要随切换更新的显示字符串；在渲染或事件处理时调用 `t`。业务键、枚举、DOM 选择器、协议字段保持稳定，不进行翻译。
5. 不对导入的备忘录、卡片名称、网址、分组名称调用翻译。`localizeSeed` 仅用于创建新的内置默认内容。

静态 HTML 使用显式标记：

```html
<span data-i18n="添加">添加</span>
<input data-i18n-placeholder="搜索备忘录"
       data-i18n-aria-label="搜索备忘录">
```

`localizeDocument` 只遍历这些标记及 `data-i18n-title`，不会扫描或改写用户内容。带嵌套图标的按钮应标记文字 span，避免替换整个按钮后删除图标。

## 组件 API

`render({ item, config, escapeHtml, t, locale })` 可获得当前语言；`mount` / `update` context 还提供 `formatDate`、`formatNumber`。切换语言会重新渲染并重新挂载组件，原来的 `AbortSignal` 终止。异步回包遵循卸载检查，不能回写旧语言界面。组件目录的标题 / 描述及声明式 fields 的标签、选项标签也会翻译；将其中文源文案加入目录即可。

## 新增语言

1. 新建 `src/messages-xx.js` 并具名导出目录；键与中文源文案一致。
2. 在 `i18n.js` 导入并加入 `catalogues`，使用 BCP 47 语言代码。`LANGUAGES` 与当前格式校验从该表读取；语言自动匹配优先完整代码，其次语言族，最终回退英语。
3. 在设置语言选项中添加语言的自称；需要本地化扩展元数据时新增浏览器要求的 `_locales/<code>/messages.json`。
4. 补充语言解析、占位符、日期 / 数字、页面切换与新默认内容测试。检查长标签、缩放、窄屏与两种主题；若添加 RTL 语言，必须同时实现并验证 `dir` 和方向布局，目前只提供 LTR。
5. 重新生成 `Qiye-preview.html`、运行 `tests/daily-widgets-e2e.py --preview`，发布时同步更新网页端。源码 `.js` 与 `_locales/*.json` 会进入扩展包。

```sh
npm test
python scripts/build-preview.py
python tests/daily-widgets-e2e.py
python tests/daily-widgets-e2e.py --preview
```

测试固定浏览器语言，分别检查中英界面、用户内容保留、自动默认语言、保存失败、城市搜索及独立 HTML。Node 测试默认使用 `tests/setup-locale.mjs` 设置中文，避免受开发机语言影响；语言专项测试显式切换并恢复。
