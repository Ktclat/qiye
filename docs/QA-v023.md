## 代码审查中修复的边界

1. 右侧收起导航的 CSS 优先级高于展开规则，已提高展开规则的优先级。
2. 快捷键提示的 hover/focus 规则压过 Esc 隐藏规则，已修复隐藏规则优先级。
3. 搜索框单独固定或向右偏移时可能与工具栏重叠，现根据真实横向交集预留工具行。
4. 中等宽度窗口的大时钟按可用宽度缩小；扩大窗口后恢复所设字号。搜索和日期保留最小间距。
5. 头像解码与重置带有请求、面板和桌面状态守卫，避免覆盖新选择或新桌面；失败不会保留虚假的处理中提示。
