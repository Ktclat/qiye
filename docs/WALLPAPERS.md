# 壁纸中心与来源接入

更新至 v0.10.8。点击“发现壁纸”组件或右上角壁纸按钮，打开同一个双栏窗口。左侧直接列来源，不显示“在线图库”“更多灵感”等组标题；参数按钮在左栏底部。右侧浏览和应用图片。

| 来源 | 当前实现与边界 |
| --- | --- |
| 自定义背景 | 已上传图片/视频在本机图库中保留，单项最大 4 MiB；仅当前选用的背景进入用户桌面备份及 WebDAV |
| 官方背景 | 6 款栖页原创 CSS 渐变，离线可用；不是 iTab 的私有资源 |
| deepin | 7 张官方开放目录背景，固定仓库提交，原图直连；4 张一页，保留 UnionTech 署名和 CC BY 4.0 |
| Wallhaven | 23 张 SFW general 精选，2026-10-12 官方 API 清单快照，12 张一页；缩略图和原图直连，**不是实时搜索或实时月榜** |
| Lorem Picsum | 公开清单 API、固定照片 ID、分页，保留摄影师和原始照片来源 |
| Wikimedia Commons | 官方 MediaWiki API；筛选横向、足够尺寸、明确 CC BY/CC BY-SA/公共领域许可的位图，保留每张图的文件页和许可 |

Unsplash/Pexels 原先只有网站外链的栏目已删除，不再以入口数量代替可用图库。用户已有桌面收藏不受影响。没有增加其他需要未配置密钥、许可用途不明确或无法直接加载图片的占位来源。

## v0.10.8：已上传的壁纸

“自定义背景”在上传入口下方显示本机图片和视频，包含缩略图、文件名、大小和“正在使用”标记。沿用图库的悬停 / 键盘操作和同窗预览；视频预览带播放控件，卡片不自动播放。上传后自动选用，之后可以预览、重新选用或确认删除。删除当前背景恢复内置背景；删除其他条目不改变桌面。

上传媒体以 Blob 存入独立的 IndexedDB `qiye.wallpapers.v1`，每项处理后最多 4 MiB，图库最多 50 项或 100 MiB；浏览器实际可用配额可能更小。SHA-256 内容标识避免重复保存同一文件，并在一次读写事务中检查容量和写入，事务提交后才报告成功。满额时保留原内容并允许删除旧条目后重试。切换来源或关闭窗口释放缩略图对象 URL；取消中的异步读取和选用不能覆盖后续选择。

刷新、切换壁纸、更新扩展均保留当前浏览器的上传记录；清除站点数据 / 卸载扩展会删除记录。扩展、独立 HTML 和不同网站来源各有自己的图库。图库不进入桌面 JSON、公开排布分享或 WebDAV，避免多张媒体突破桌面备份的 6 MiB 限额；当前选用的媒体仍按原规则随桌面保存与同步。重置桌面保留图库，需要清除的条目可在此单独删除。

启动或打开图库时会收录当前设置中已有的自定义背景；旧版本已被替换且未保存的历史上传无法恢复。上传新背景前也会先保留当前背景。图库没有额外服务器请求，不申请新增扩展权限。

实现依据与选择：

- [MDN：Using IndexedDB](https://developer.mozilla.org/en-US/docs/Web/API/IndexedDB_API/Using_IndexedDB)：使用结构化记录保存 Blob，等待事务完成，不把单个写请求成功等同于完整保存。
- [MDN：Using files from web applications](https://developer.mozilla.org/en-US/docs/Web/API/File_API/Using_files_from_web_applications)：沿用本机文件选择与对象 URL 预览，在视图销毁后释放 URL；不把整库媒体编码进同步设置。

回归覆盖源码、独立预览和真实 MV3 扩展：图片 / 视频上传、重复内容、预览与选用、刷新持久化、取消删除、删除当前背景、旧背景收录、过大文件、深浅色和 390 px 窄屏。真实 IndexedDB 另外验证并发去重、满额拒绝保留原数据及删除后继续写入；测试入口为 `tests/local-wallpaper-e2e.py`。

## deepin 与 Wallhaven 如何工作

deepin 使用官方 `linuxdeepin/deepin-wallpapers` 仓库提交 `caae39a555fbeac36da0cacc0fd00d73b2706c7e` 的 `deepin/` 目录。官方 `.reuse/dep5` 对这些 JPG/PNG 声明 CC BY 4.0；不读取 `nonfree/` 中的受限图片。固定版本避免将未复核的新素材自动加入；图片文件留在原站，不复制到栖页仓库。该来源没有独立缩略图服务，故每页限制 4 张并懒加载。

Wallhaven 使用官方 API 返回的真实 `path`、`thumbs.large`、尺寸、SFW 标记和来源页。本次响应可正常读取，但未返回允许 Pages origin 的 CORS 响应头。因此采用带日期的元数据快照，而不是客户端重复发注定失败的跨域 API 请求。图片可单独从 `th.wallhaven.cc` / `w.wallhaven.cc` 加载。**图片版权仍归原权利人，不代表可以全部商用或重新分发。** 所有条目保留来源与版权提示，不提供绕过鉴权的内容。

源码 `wallpaper-catalog.js` 仅包含元数据清单。新版本维护者可核验上游后更新日期与条目；当前没有定时后台更新、第三方代理、隐藏 API key 或自建图床。项目未正式推出，失效或不合适的条目可直接移除，不保留历史条目或迁移逻辑；备份中的来源必须满足当前清单和校验规则。

## 隐私与性能

默认不请求图库。主动进入在线来源且启用后才加载；桌面卡片是入口，不预拉整库。API 清单缓存只保留最近 5 个“来源 + 页码”。缩略图懒加载；选择图片后才预载完整背景。切换来源和关闭弹窗取消旧任务；失败保留背景，不提示假成功。

Picsum 使用 `/v2/list`。Commons 每页最多 18 张、640 缩略图；应用时使用 API 实际返回的高清 URL。Commons 超时约 12 秒、文本响应上限 2 MiB；完整背景预载期限 15 秒。Deepin 单张选择不超过 2.5 MB，Wallhaven 快照仅收录不超过 12 MiB 的原文件元数据；上游实际响应仍受浏览器策略影响。

请求不携带搜索词、便签、WebDAV 凭据或整个桌面清单。图片主机可看到客户端 IP 和普通请求信息。图库许可与 GPLv3 分开，不把所有外部图片重新标记为 GPL。

## 新来源的实现合同

只有能在面板中直接浏览/应用的来源才进入 `WALLPAPER_SOURCES`。API 或已审查元数据快照都可设置 `endpoint: true` 并提供 fetcher；快照还须 `snapshot: true`、明确日期/来源说明和分页上限。不再添加仅外链栏目。

标准记录：`provider,id,title,author,width,height,url,thumbnail,sourceUrl,license,licenseUrl`。在 `wallpapers.js` 接入 `normalizeWallpaperPhoto()`，逐项校验 URL、域名、端口、路径、尺寸、图片 ID 与来源；目录来源必须匹配可信条目，不能把导入备份中的任意 URL 视作可信背景。

fetcher 支持 `{page, signal}` 并返回有界数组。网络错误抛给界面；请求不能在 render 中触发；用户同意须成功保存后才继续。API key 不得进静态 Pages、Git、桌面 JSON 或日志。需要密钥的新服务先设计本机配置/合规用途，不能共享硬编码密钥。

本轮只新增并验证两个明确来源，没有声明“所有热门图库均支持”。新增来源应提交真实接口/许可证据，以及分页、取消、失败和深浅主题测试。

## v0.3.2：预览与选择

“壁纸库”标题放在左栏上方，右栏独立滚动。保留自定义、官方、deepin、Wallhaven、Picsum、Commons 六个入口，不添加只打开外部网站的占位来源。每个在线来源顶部只出现一次图片权利说明；缩略图本身不反复附加相同说明。

鼠标悬停 / 键盘聚焦显示“预览”和“选用”，触屏下直接展示操作。预览是同一弹窗右侧的详情视图，不叠加新的模态窗口；作者、原始文件页和许可在详情中可见。Esc 或返回按钮先回到图库。预览不修改背景，选用才通过预载和状态检查保存。切源、换页、关闭会取消旧请求；异步完成不得覆盖新的选择。参数入口固定在左栏底部。

Deepin 和 Wallhaven 仍是注明版本 / 日期的已审查快照，不因为窗口重制就变成实时 API。图库图片可用性、授权范围和快照维护规则保持不变。

## 本地壁纸自动压缩（2026-10-16）

静态 PNG、JPEG 和 WebP 上传时共用图片压缩引擎。单张原图上限 32 MiB、24 MP，不更改分辨率；优先尝试高画质 WebP，若输出更大保留原图，并在写入桌面状态前强制检查 4 MiB 限额。超过限额而无法压缩成功时保留既有壁纸并报错。可解码但无法压缩的 4 MiB 内原图仍可使用；GIF、AVIF 和 MP4/WebM 不经过静态图片编码器，保持原先 4 MiB 限额。压缩前的数据只在当前窗口短暂保留，不提交至备份/WebDAV。

“图片压缩”小组件提供单张/批量 PNG、JPEG、WebP 处理、滑动预览、逐图下载、ZIP 下载及设为壁纸。真正无损模式仅处理 PNG：保留全部像素和色彩信息，尝试重压缩 DEFLATE 图像数据，删除文字/时间注释；WebP/JPEG 使用有损重编码，不宣称像素无损。暂不支持动画压缩、AVIF 重编码或 WASM 编码器。Chrome/Edge 扩展与生成的网页版均不需要请求额外网络权限。
