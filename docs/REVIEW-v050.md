# v0.5.0 代码审阅与改进

日期：2026-10-13。需求为完善 iTab 风格日历、备忘录、天气，加入国际化，降低维护成本，并同步网页端。项目处于开发阶段，直接采用 schema 3，不保留历史格式读取或迁移。

## 发现与修复

| 原有问题 | 本次处理 |
| --- | --- |
| 日历仅显示月份，缺少日程和日期工具，日期算法散落在组件中 | `calendar.js` 统一本地日期 / ISO 周 / 已核实调休；卡片进入独立详情，支持日程与日期工具 |
| 单张便签承担所有记事场景 | 保留轻量便签，新增 `memo` 多记录模型；独立列表 / 编辑区支持搜索、排序、置顶、导出和撤销 |
| 天气城市是全局设置，网络和 SVG 混在大组件文件中 | 删除全局天气设置；每张卡片保存城市与单位；`weather.js` 管理请求、解析、缓存和错误，视图单独消费数据 |
| 界面文案、日期、错误只能用中文 | 共享 i18n 层与英文目录；浏览器自动识别 / 手动切换；扩展元数据、右键收藏、popup、主页面与预览共同更新 |
| 编辑和持久化共享可变对象，失败回滚可能吃掉新输入 | 独立 `widget-drafts.js` 快照与串行保存；自动提交后续输入，拒绝覆盖已被别处修改的同一组件，保留失败草稿及导出入口 |
| 备忘录删除撤销依赖弹窗外 toast，原生 modal 阻挡点击 | 撤销移动到备忘录详情内；新建 / 切换立即更新编辑区，避免等待保存时输入错条目 |
| 关闭窗口只发起保存，立即刷新可能早于异步写入 | 关闭按钮 / Escape 等待提交，保存期间停止编辑；用延迟 Web Locks 回归，发布失败的未发布版本可在修复后重推恢复 |
| 源码与预览构建模块命名限制未覆盖 i18n，分发清单漏语言目录 | 构建器接受数字模块名，扩展包明确包含 `_locales`；生产模块和独立 HTML 使用同一浏览器回归 |
| 旧线上验证脚本写死版本和存储键 | 改为读取当前 manifest 和生产存储键；校验已部署文件与同源构建，再验证语言 / 组件 / 缩放 |

## 架构边界

日期和备忘录模型不依赖 DOM；天气服务不操作视图；详情渲染和事件分别放在 `widget-detail-views.js` / `widget-details.js`。草稿保存通过 `saveWidgetData` 接入现有桌面事务，WebDAV、备份、popup 继续经过同一严格校验。i18n 不向业务模块引入 DOM 副作用，不修改用户文本，扩展 API 提供翻译和格式化函数。

## 对照范围

参考 [iTab 官方更新记录](https://www.itab.link/changelog.html) 和 [公开页面](https://go.itab.link/)。按可核实的月份 / 年度统计 / 日期工具、备忘录列表 / 整理、城市天气等操作完善；没有使用私有接口，未把网络环境中无法完整检查的功能标为逐项一致。完整能力表与边界在 [WIDGETS.md](WIDGETS.md#日常组件功能与数据来源)。

## 仍需持续维护

- 中国调休表必须每年以官方通知更新；其他年份与全球法定假日暂不推测。
- `app.js` 仍承担桌面和多个设置页的组合；后续按功能拆设置视图，避免为了拆文件一次改写所有稳定流程。本版先抽离新增业务和数据算法。
- 不提供日历循环提醒、系统通知、富文本或附件；这需要新的数据模型与明确产品交互。
- 翻译目前为中英两种 LTR 语言；新语言应同时完成词条、元数据、长文案布局及浏览器回归。
- 上游天气 / 地名 / 空气质量存在可用性和覆盖边界；缓存、缺值和部分失败可处理，不能保证上游始终在线。
- 完整扩展安装 / 权限弹窗、真实个人 WebDAV 服务、触屏与低功耗硬件性能不由 HTTP 夹具测试代替，详见 [QA.md](QA.md)。
