# 栖页 Qiye · 隐私与权限

版本：v0.2.1　更新：2026-10-11

## 本机保存与公开网站

栖页没有账号服务器、广告脚本或行为遥测。扩展桌面保存在 `chrome.storage.local`，网页桌面保存在该站点的 `localStorage`。公开体验链接不会公开个人桌面；不同浏览器、设备和访问者各自保存数据，只有用户连接相同 WebDAV 文件后才会共享该文件。

桌面和备份包含网址、便签、待办、布局、设置及所选本地素材。每个网站的图标模式 `iconMode`（`auto` / `text`）会进入备份与同步，提取出的图标 URL、网页 HTML 和图标缓存不会进入桌面 JSON。WebDAV 目录、用户名、密码和同步基线存放在独立本机记录中，**不进入 JSON 导出或同步文件**。本机凭据没有另行加密，依赖设备与浏览器的访问保护。

## 外部访问

| 功能 | 何时访问与发送内容 |
| --- | --- |
| 网站自动图标 | 网站卡片默认使用自动模式；加载图片会访问对应站点或其声明的图片 CDN，切换文字模式后不再为该卡片主动加载远端图标 |
| 智能提取图标 | 用户主动点击后读取目标页面的图标声明；读取地址保留路径并去掉查询参数与片段，扩展按目标站点请求访问权限 |
| WebDAV | 主动测试连接时只读取；保存并启用后，手动同步或符合条件的自动检查访问所填服务；上传完整桌面 JSON |
| 在线壁纸 | 默认关闭；启用后从 Picsum 获取照片清单和图片，显示作者与来源；暂停停止后续请求并恢复本地背景 |
| 天气 | 默认关闭；启用后将所选城市经纬度发给 Open-Meteo，不读取设备精确定位 |
| 搜索和网站 | 提交搜索时发送查询词；点击网址或平台入口时访问目标网站；输入联想来自本机收藏 |

### 网站图标的读取与缓存

自动图标使用本机已知候选、目标站点的 `/favicon.ico` / `/apple-touch-icon.png`，以及扩展中的浏览器图标回退。自动显示只加载图标图片；主动点击“智能提取”才读取网页 HTML，必要时读取该页面声明的同源 Web App Manifest。提取不执行页面脚本，不读取跨来源 manifest，也不把页面 HTML 插入栖页。网页版能否读取取决于目标站点的 CORS 设置；失败时仍可尝试图片地址或显示文字。

提取的页面 / manifest 请求去掉查询参数和片段，保留路径，使用 `credentials: 'omit'` 和 `no-referrer`；图标图片也使用 `no-referrer`，其加载遵循浏览器的图片与 Cookie 策略。页面声明的图片可以位于其他 HTTPS CDN，图标地址自身的查询参数会保留。未使用第三方 favicon 聚合或代理服务。

图标缓存以去掉查询参数和片段的页面 HTTPS URL 为键，保存候选和成功加载的图标地址及状态。扩展使用 `chrome.storage.local`，网页使用 `localStorage`，独立记录为 `qiye.favicons.local.v1`。有效期为 7 天，最多 200 个页面；读取失败暂避 10 分钟，当前页面的图片加载失败记录暂避 5 分钟。缓存不保存抓取的 HTML，也不缓存 Chrome 内部图标 URL，不进入 JSON 备份或 WebDAV。切换文字模式停止该卡片后续的主动图标加载，已有缓存可按到期策略淘汰。

### 壁纸、天气与同步

WebDAV 使用 Basic 凭据与 HTTPS 传输，仅本机 `localhost`/`127.0.0.1` 允许 HTTP；拒绝重定向。远端文件是普通 JSON，**未做端到端加密**，服务方或获准读取该目录的人可查看内容。请将它保存到自己的私有目录。凭据只发给填写的服务，不交给栖页托管服务器。

壁纸缓存为 24 小时，天气缓存为 30 分钟，缓存与历史查询结果不进入备份。外部服务会收到网络连接必需的信息，并按自己的政策处理访问。恢复已启用联网功能的备份后，会按相应设置请求服务。

## 权限与清除

`storage` 保存数据；`activeTab` 和 `contextMenus` 用于主动收藏当前页或链接；`favicon` 用于扩展版的浏览器图标回退。书签与历史权限按需申请。Picsum 使用固定站点访问权限；WebDAV 连接和网站图标智能提取分别按用户操作申请目标来源的可选权限，不自动获得所有网站权限。`favicon` 权限不等于网站 HTML 读取权限。

“暂停同步”保留配置和数据；“清除本机连接”删除该浏览器中的 WebDAV 凭据与同步记录，保留桌面和远端文件。清除网站数据或卸载扩展不会删除已经导出的文件及 WebDAV 备份。重置桌面不直接删除远端文件，但启用的自动同步会继续同步桌面变化；远端文件需在自己的服务中管理。

本地媒体上限 4 MiB，备份上限 6 MiB。导入校验只接受支持的本地媒体及经过固定提供方校验的在线壁纸，壁纸字段拒绝任意远程图片地址；网站图标只保存经过校验的模式和原有文字回退，不接受备份中的远端图标 URL。运行与网络验收限制见 [QA.md](QA.md)。

浏览器存储说明：<https://developer.chrome.com/docs/extensions/reference/api/storage>。外部 API 与协议出处见 [README](../README.md#官方参考)。
