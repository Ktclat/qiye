# 栖页 Qiye · 隐私与权限

版本：v0.9.1　更新：2026-10-15（香港时间）

## 分享与社区组件

“分享与导入”生成的排布文件包含用户选中的分组、网站、文件夹和组件尺寸 / 顺序；组件个人内容清空，内置组件配置恢复默认。外观可选择包含，但不会导出自定义壁纸媒体、头像、WebDAV 凭据或搜索记录。公开网站 URL 与图标会随排布分享，请在发布前查看是否含私人链接或查询参数。完整备份与 WebDAV 仍包含个人桌面内容，不能当成公开分享文件。

分享链接打开后只填写地址，点击“读取并预览”才请求该地址；导入还需确认。联网读取使用公开 HTTPS、不发送 Cookie 或 Referer、拒绝重定向，网页版要求 CORS。扩展在用户操作时使用已有可选域名权限，不增加强制权限。

社区来源与缓存仅保存在本机 `qiye.community.v1`，最多 20 个来源，不进入桌面备份和同步。打开社区页会加载作者预览图；目录需主动读取 / 刷新。安装后的清单与实例数据属于桌面，随备份和 WebDAV 保存，但排布分享会清空实例数据。

社区组件只有在专用窗口点击“运行”后才加载作者网页。iframe 隔离宿主 DOM、其他组件内容和凭据，接口只提供自己的 JSON 数据与主题 / 语言 / 尺寸；限制每实例 64 KiB。关闭或停止卸载网页。作者页面仍能联网并接收本组件数据及正常网络元数据；其隐私行为与远程内容由作者负责。不要向第三方组件输入密码。运行域名、源码与许可可在运行前查看。[完整接口与边界](COMMUNITY.md)。

## 热搜榜数据

热搜榜默认关闭后台自动更新；主动打开榜单、切换平台或刷新时，按所选来源向 `uapis.cn` 请求公开榜单，GitHub 新星榜向 `api.github.com` 发送固定的创建日期 / topic 查询。管理订阅中也可指定兼容 DailyHotApi 的公开 HTTPS 服务。请求不带 Cookie 或 Referer，不发送桌面内容、平台搜索输入或其他订阅名单；服务仍会收到正常网络元数据。扩展使用已有可选域名权限，在主动查看或更换来源时按需申请。

订阅、排序、当前平台、视图、自动更新开关和服务地址随组件设置进入备份及 WebDAV。榜单缓存独立存于本机 `qiye.hotsearch.v1`，最多 48 份、7 天，不进入备份或同步；10 分钟内复用缓存，刷新失败仍可查看旧榜。关闭组件窗口会取消无其他消费者使用的请求。公开排布分享恢复默认配置，导入时关闭后台自动更新。关闭自动更新不会清除已缓存的榜单；再次主动打开仍会按需读取。

## 页底一言

“显示页底短句”默认开启。每次打开或刷新页面、重新开启此项，或点击底部句子时，向 `v1.hitokoto.cn` 获取随机一言。请求仅包含句子长度、JSON 格式与临时随机参数，不携带 Cookie、Referer、桌面内容或用户标识；服务会收到正常网络元数据。关闭此项后停止请求并取消正在进行的读取。使用服务提供的 CORS 支持，不增加扩展权限。

最近 12 条成功获取的句子及最后显示的文本保存在独立本机 `localStorage` 键 `qiye.daily-quote.v1`，用于避免连续重复和断网回退，不进入桌面备份、分享或 WebDAV。服务返回重复文本时最多请求 3 次，单页请求间隔至少 650 毫秒，总等待上限 8 秒；失败时优先轮换真实缓存，没有其他缓存时显示标明来源的本地短句。点击旁边的“一言”链接可查看服务原始出处。

## 主动访问后获取图标

点击“访问网站取图标”会打开完整的目标网址，属于用户主动的普通网页访问，网站可按浏览器规则使用 Cookie / 登录状态。栖页只等待本次创建的标签页和原编辑器之间的返回 / 关闭事件，然后读取浏览器本地 favicon 缓存；不注入脚本、不读取网页正文、不导出 Cookie、不新增 `tabs` / 历史权限，也不把访问记录发送到其他服务。

等待最多两分钟，取消、关闭 / 替换编辑器或修改网址会清理监听和定时器；不自动关闭已打开的网站。读取的静态 PNG 只加入当前表单候选，选中并保存后才进入卡片 `iconUrl`，会随用户选择的 JSON 备份或 WebDAV 同步。未保存的候选不会写入桌面。网页端无法读取其他标签页，保留主动访问和本机上传入口；本地 PNG 可在网页端显示。技术边界见 [图标文档](FAVICONS.md#访问后读取标签页图标)。

## 本机保存与公开网站

栖页没有账号服务器、订阅中心、广告脚本或行为遥测。扩展桌面保存在 `chrome.storage.local`，网页桌面保存在该站点的 `localStorage`。公开体验链接不会公开个人桌面；不同浏览器、设备和访问者各自保存数据，只有用户连接相同 WebDAV 文件后才会共同访问该文件。

桌面 JSON 与独立本机记录的边界如下：

| 数据 | 保存位置与同步范围 |
| --- | --- |
| 网站、分组、文件夹、布局、日历日程、备忘录、便签、待办及组件设置 | 本机桌面；进入 JSON 导出和 WebDAV 同步 |
| 语言、主题、材质、字体选择、字号、导航、工具显示、时间和搜索框位置/固定方式、搜索模板 | 本机桌面设置；进入备份与同步 |
| 自定义头像与所选本地壁纸 | 图像/媒体数据随桌面保存；进入备份与同步 |
| 最近搜索开关 | 桌面设置，进入备份与同步；不包含具体搜索记录 |
| 最近搜索记录 | 独立本机 `localStorage`，默认不记录，最多 20 条；不备份、不同步 |
| 网站与搜索引擎图标缓存 | 独立本机记录；不进入桌面 JSON、导出或 WebDAV |
| WebDAV 地址、用户名、密码与同步基线 | 独立本机记录；不进入桌面 JSON、导出或 WebDAV 同步文件 |

本机 WebDAV 凭据没有另行加密，依赖设备与浏览器的访问保护。拖动、位置调整、主题和材质设置本身不需要外部服务。

### 本地头像

“侧边栏”设置可选择本地 PNG、JPEG、WebP，输入文件上限 **4 MiB**。栖页在浏览器本机校验、解码、居中裁切，并重新生成 **256×256 的静态方形图像**，保存后的图像数据不超过 **256 KiB**。图片处理不会请求头像服务器，也不会用图片建立账号。

生成的头像以受限的本地 `data:` URL 保存。JSON 导入同样校验类型、容器、静态格式与大小，拒绝任意远程头像 URL 和 SVG。上传的动图格式若可解码，只保存生成的静态结果；原文件不作为头像附带保存。

头像属于桌面设置，会进入导出的备份，也会上传到用户启用的 WebDAV 服务。恢复默认头像会改变本机桌面设置；已经导出的旧备份不会被删除，启用同步后会按正常同步规则处理头像变化。

### 最近搜索

“保存最近搜索”默认关闭。关闭时不读取、记录或展示最近搜索；开启后只记录用户实际提交的查询，最多保留 **20 条去重记录**，每条最多 240 个字符。记录单独保存在当前来源的 `localStorage` 键 `qiye.search-history.v1` 中，不读取系统搜索历史，也不会发到栖页服务器。

关闭开关会停止记录和显示，但不是删除已有记录；“清除最近搜索”可以单独删除本机记录，即使开关已关闭也能清除。此记录不进入 JSON 导出或 WebDAV，同步或导入的开关偏好不会带回另一台设备的查询内容。搜索提交本身仍会把查询词发给用户选中的搜索引擎。

最近搜索与“浏览历史”查询是两个独立功能：后者需要扩展的浏览历史权限，仅按用户明确提交的关键词查询浏览器历史，不把结果加入桌面备份。

### 本地字体与视觉效果

Inter 字体随扩展和演示构建提供，约 **71.21 KiB**，使用 OFL 1.1 许可；中文和其他未包含字符使用设备字体。运行时不从 Google Fonts、字体作者的网站或字体 CDN 请求文件。字体选择、透明度、毛玻璃、亚克力、Mica 风格和动画设置不上传设备数据。Mica 风格是 CSS 视觉效果，不调用 Windows 原生 Mica 接口。

### 网站与搜索引擎图标的读取与缓存

正常图标优先加载图片；开启“自动补充高清图标”后，在图片缺失或实际像素不足时可有限地读取公开 head、同源 Manifest 或 ICO 原生帧。候选包括已有站点声明、`/favicon.svg`、`/apple-touch-icon.png`、`/favicon.ico` 和扩展浏览器图标回退。图标按目标显示大小、屏幕像素比、声明及实际图片尺寸排序；屏幕像素比仅在本机计算所需图片尺寸，不发送独立遥测。

已有图片清晰度不足时，保留当前图标并最多尝试 3 个更合适的候选；同一站点相同或更小尺寸的自动升级需求有 24 小时冷却。加载到更大图像会更新本机尺寸记录。此过程仍只访问站点自身或其声明的图片地址，不使用第三方 favicon 聚合、代理、图像增强或抠图服务。

主动点击“智能提取”可以重试读取页面 HTML，必要时读取该页面声明的同源 Web App Manifest；自动补充也可在已有权限内读取相同的有限元数据。提取不执行页面脚本，不读取跨来源 manifest，也不把页面 HTML 插入栖页。网页版是否允许读取取决于目标站点的 CORS；失败时仍可尝试图片地址或显示文字。

内置与自定义搜索引擎共用上述机制。栖页从搜索模板取出来源，例如 `https://example.com/search?q={q}` 使用 `https://example.com/`。已知的哔哩哔哩搜索子域使用对应主站，其他来源保留原子域；图标请求不包含搜索框输入，也不请求模板指定的搜索结果路径。查询词只在用户提交搜索时交给所选引擎。引擎图标没有人为增加的白底，但原始图片自己的背景会保留。

页面 / manifest 请求去掉查询参数和片段、保留路径，使用 `credentials: 'omit'` 和 `no-referrer`；图标图片也使用 `no-referrer`，其加载遵循浏览器的图片与 Cookie 策略。提取仅处理公开 HTTPS 域名，拒绝 localhost、IP 地址、自定义端口或跨来源跳转。网页声明的图片可以位于其他 HTTPS CDN，图标图片地址自身的查询参数会保留。

自动提取缓存以去掉查询参数和片段的页面 HTTPS URL 为键，引擎使用相应首页作为键，记录候选、成功地址、声明与实测尺寸、状态及冷却信息。扩展使用 `chrome.storage.local`，网页使用 `localStorage`，网站和引擎共用独立记录 `qiye.favicons.local.v2`。有效期 7 天，最多 200 个页面；读取失败暂避 10 分钟，当前页面的图片加载失败记录暂避 5 分钟。自动缓存不保存网页 HTML，也不保存 Chrome 内部图标 URL，不进入 JSON 备份或 WebDAV。切换文字模式停止该卡片后续的主动图标加载，已有缓存可按到期策略淘汰。

### 壁纸、天气与同步

WebDAV 使用 Basic 凭据与 HTTPS 传输，仅本机 `localhost` / `127.0.0.1` 允许 HTTP；拒绝重定向。远端文件是普通 JSON，**未做端到端加密**，服务方或获准读取该目录的人可查看内容，应保存到自己的私有目录。凭据只发给填写的服务，不交给栖页托管服务器。

壁纸中心会话内至多缓存 5 个来源/页码，旧 Picsum 元数据缓存仍受 24 小时上限约束；天气面板的最近城市列表仅保存在本机，最多 8 个城市，不进入备份、WebDAV 或分享文件；天气已启用时会按地区和选定来源读取列表城市概况；Open-Meteo 提供补充预报与空气质量。天气缓存有效期为 30 分钟，最多保存 48 个城市/来源组合，保留 7 天旧预报用于断网查看。和风 API Host / Key、气象署授权码存放在独立本机记录 `qiye.weather.credentials.v1`，仅发送给对应官方接口，可在天气设置中清除，不进入桌面备份、WebDAV 或分享文件。缓存与浏览历史查询结果也不进入备份。外部服务会收到网络连接必需的信息，并按自己的政策处理访问。恢复已经开启联网功能的备份后，会按相应设置请求服务。

## 书签小组件

“独立收藏”按组件保存在本机桌面中，会进入 JSON 备份和 WebDAV；公开排布分享会清空这些收藏。未授权时不会读取或修改浏览器原生书签。“连接浏览器书签”按需申请 `bookmarks` 权限，授权后可以直接增删改和移动原始书签及文件夹，并接收浏览器的书签变更事件。原生收藏树仅在内存使用，不进入桌面 JSON、WebDAV 或公开分享；浏览器自身的书签同步由浏览器管理。

切换收藏来源不会合并两套数据。拒绝授权、撤销权限或在网页版中使用时，独立收藏仍可管理。删除组件或恢复桌面不删除原生浏览器收藏；在浏览器来源中确认删除某条收藏或文件夹则会直接删除原始内容。组件用域名首字母区分网站，浏览收藏列表本身不请求收藏网站的图标或页面。


## 权限、重置与清除

`storage` 保存数据；`activeTab` 和 `contextMenus` 用于主动收藏当前页或链接；`favicon` 用于扩展版浏览器图标回退。书签与历史权限按需申请。Picsum 使用固定站点访问权限；WebDAV、网站和搜索引擎图标提取分别按用户操作申请目标来源的可选权限，不自动获得所有网站权限。`favicon` 权限不等于网站 HTML 读取权限。头像只通过用户选择的本地文件处理，不需要读取整个磁盘的权限。

“暂停同步”保留配置和数据；“清除本机连接”删除该浏览器中的 WebDAV 凭据与同步记录，保留桌面和远端文件。清除站点数据或卸载扩展不会删除已经导出的文件及 WebDAV 备份；备份文件和远端副本需由用户自行管理。

“重置设置”恢复显示、搜索、头像和壁纸偏好，保留网站、分组与组件内容；“恢复初始桌面”替换桌面数据。两者不直接删除远端文件，但启用的自动同步仍会按同步规则处理桌面变化。最近搜索记录可通过独立的清除按钮删除。

本地壁纸媒体上限 **4 MiB**，头像输入上限 **4 MiB**、保存图像上限 **256 KiB**，整个备份上限 **6 MiB**。导入只接受支持的本地媒体及经过固定提供方校验的在线壁纸，壁纸字段拒绝任意远程图片地址；网站图标保存经过校验的模式、文字回退和用户显式选择的 `iconUrl`（安全 HTTPS 图片地址或有界静态本机图片）。网页还受浏览器存储配额限制。

运行与网络验收边界见 [QA.md](QA.md)。字体来源和完整许可见 [THIRD_PARTY.md](THIRD_PARTY.md)。浏览器存储说明见 [Chrome Storage API](https://developer.chrome.com/docs/extensions/reference/api/storage)，外部 API 与协议出处见 [使用指南](GUIDE.md#官方参考)。


## v0.3.1 图库与界面补充

新增 Commons 来源使用 `commons.wikimedia.org/w/api.php` 和 `upload.wikimedia.org` 的 HTTPS 位图；明示启用后按用户选择来源获取，不在新标签页组件渲染时获取列表。仅接受已识别的 CC/公共领域许可并保留来源，不转发凭据。图库面板已移除 Unsplash/Pexels 外链入口；Deepin/Wallhaven 图片直接从各自的原站加载。清单缓存仅在当前页面内保留最近 5 页。

拖动预览不写存储；松手才提交。侧栏滚轮模式、内容滚动条设置进入桌面备份。头像/本地壁纸只本机读取但会随用户选择的备份/WebDAV 同步；不称为零联网同步。界面行为不收集统计数据。细节见 [壁纸文档](WALLPAPERS.md)。

## v0.3.1 图标补充与壁纸来源

默认开启“自动补充高清图标”。正常图标失败或实际像素不足时，页面可能读取目标网站公开 HTML 的 head、同源 Manifest，或者下载最多 1 MiB 的 ICO 来提取其中真实的大尺寸帧。请求删除查询与片段，省略凭据和 Referer，不运行目标网页脚本；扩展只使用已有权限，不自动申请新权限。可在侧栏“图标”入口关闭。关闭后仍允许正常图片显示和用户主动提取。

常用站点的已核验首方/CDN 图标地址随源码提供，图片运行时从其来源加载；不打包商标图像，也不把整个收藏列表交给图标代理。请求目的站点会获知客户端 IP 和访问其资源这一事实。

图标清晰度、候选地址缓存仍独立于桌面。ICO 原生帧解码为本机 PNG 缓存，键为 `qiye.icon-artwork.v1`，最多 16 条、约 2.4 MB 文本容量、7 天有效；不进入 JSON 备份或 WebDAV。缓存失败不会清除桌面。

启用壁纸图库后，Deepin 图片连接 raw.githubusercontent.com；Wallhaven 缩略图连接 th.wallhaven.cc，完整图片连接 w.wallhaven.cc。两个来源使用随版本分发的元数据精选清单，不是客户端无期限轮询原网站。旧的 Unsplash、Pexels 仅外链栏目已移除；已有用户收藏中的同名网站不删除。作者与许可/来源链接保留，不代表所有图片有相同授权。

## v0.3.2：明确选择的网站图标

网站编辑器不会把候选列表发送到栖页服务器；栖页没有这类服务器。点击“获取图标”只读取目标站点公开 HTML / 同源 Manifest 及它们声明的图片，省略 Cookie、认证和 Referer。访问图片时图片服务仍会看到客户端 IP 与一般请求信息。读取权限与 CORS 的限制不因新增选择功能而放宽。

主动选定的图像地址以 `items[].iconUrl` 保存，与自动图标缓存分开。用户上传的静态图标在本机裁切 / 编码后也保存在这个字段。两者均进入用户主动导出的 JSON 或其自行配置的 WebDAV，供其他设备保留同样的图标；WebDAV 凭据仍不进入桌面备份。取消编辑不保存草稿。既有不含该字段的备份继续按自动图标逻辑显示。

壁纸预览只在当前窗口加载图片，只有点击“选用”才保存背景；预览详情保留作者与原始来源链接，不执行来源页面中的脚本。

## v0.3.3：跨站图标选择与滚动条

打开网址和图标来源可以不同，这是用户在编辑表单中的明确选择。获取的候选列表仅存于当前表单内存，不写入桌面备份；选定并保存的 iconUrl 仍随桌面备份 / WebDAV 同步。修改网址不清除已有选择，也不自动扩大网站访问权限；图标提供方仍能看到图片请求。未完成的旧提取结果不会覆盖新草稿。hideEditorScrollbar 是独立布尔偏好，进入桌面备份，不影响凭据或授权。
