# 栖页 Qiye · 隐私与权限

版本：v0.2.0　更新：2026-10-11

## 本机保存与公开网站

栖页没有账号服务器、广告脚本或行为遥测。扩展桌面保存在 `chrome.storage.local`，网页桌面保存在该站点的 `localStorage`。公开体验链接不会公开个人桌面；不同浏览器、设备和访问者各自保存数据，只有用户连接相同 WebDAV 文件后才会共享该文件。

桌面和备份包含网址、便签、待办、布局、设置及所选本地素材。WebDAV 目录、用户名、密码和同步基线存放在独立本机记录中，**不进入 JSON 导出或同步文件**。本机凭据没有另行加密，依赖设备与浏览器的访问保护。

## 主动启用的外部访问

| 功能 | 何时访问与发送内容 |
| --- | --- |
| WebDAV | 主动测试连接时只读取；保存并启用后，手动同步或符合条件的自动检查访问所填服务；上传完整桌面 JSON |
| 在线壁纸 | 默认关闭；启用后从 Picsum 获取照片清单和图片，显示作者与来源；暂停停止后续请求并恢复本地背景 |
| 天气 | 默认关闭；启用后将所选城市经纬度发给 Open-Meteo，不读取设备精确定位 |
| 搜索和网站 | 提交搜索时发送查询词；点击网址或平台入口时访问目标网站；输入联想来自本机收藏 |

WebDAV 使用 Basic 凭据与 HTTPS 传输，仅本机 `localhost`/`127.0.0.1` 允许 HTTP；拒绝重定向。远端文件是普通 JSON，**未做端到端加密**，服务方或获准读取该目录的人可查看内容。请将它保存到自己的私有目录。凭据只发给填写的服务，不交给栖页托管服务器。

壁纸缓存为 24 小时，天气缓存为 30 分钟，缓存与历史查询结果不进入备份。外部服务会收到网络连接必需的信息，并按自己的政策处理访问。恢复已启用联网功能的备份后，会按相应设置请求服务。

## 权限与清除

`storage` 保存数据；`activeTab` 和 `contextMenus` 用于主动收藏当前页或链接。书签与历史权限按需申请。Picsum 使用固定站点访问权限；WebDAV 在首次连接时申请所填服务来源的可选权限，不自动获得所有网站权限。

“暂停同步”保留配置和数据；“清除本机连接”删除该浏览器中的 WebDAV 凭据与同步记录，保留桌面和远端文件。清除网站数据或卸载扩展不会删除已经导出的文件及 WebDAV 备份。重置桌面不直接删除远端文件，但启用的自动同步会继续同步桌面变化；远端文件需在自己的服务中管理。

本地媒体上限 4 MiB，备份上限 6 MiB。导入校验只接受支持的本地媒体及经过固定提供方校验的在线壁纸，拒绝任意远程图片地址。运行与网络验收限制见 [QA.md](QA.md)。

浏览器存储说明：<https://developer.chrome.com/docs/extensions/reference/api/storage>。外部 API 与协议出处见 [README](../README.md#官方参考)。
