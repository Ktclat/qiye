## 安装后的验收路径

| 操作 | 预期结果 |
| --- | --- |
| 加载扩展后新建标签 | 显示栖页，新安装的默认主页包含在线壁纸卡片 |
| 旧版本数据升级 | 原布局保留，缺失的固定开关默认为开启；已有关闭选择保留 |
| 切换两个固定开关并滚动 | 四种组合各自生效；时间或搜索框关闭固定后随页面滚动 |
| 开启秒数并调整时钟大小 | 秒数与时分同字号，以字重和颜色区分 |
| 用鼠标直接拖网站或文件夹 | 可排序；正常点击仍能打开，拖动释放不误点开网站 |
| 使用组件或触屏手柄 | 可拖动卡片，组件文字输入和普通触摸滚动保持可用 |
| 将网站拖进文件夹或将项目拖到分组 | 保存目标布局；文件夹跨组时连同子项一起移动 |
| 拖动过程中按 Escape 或取消指针 | 取消拖动，保持未提交的布局不变 |
| 切换浅色、深色或跟随系统 | 桌面面板与 13 类组件使用对应主题，表单和状态文字可读 |
| 切换引擎或打开搜索设置 | 显示该引擎图标，失败保留文字；图标请求不包含搜索词 |
| 在搜索设置点击“提取图标” | 按站点权限或 CORS 策略读取相应站点首页，失败仍可搜索 |
| 新建网站或导入旧备份 | 默认使用网站真实图标；图片成功加载后显示，失败时保留原文字或内置图标 |
| 网站表单点击“智能提取” | 扩展按站点请求权限；显示提取状态并尝试候选，拒绝权限或网络失败时仍可保存网址 |
| 提取期间修改网址、图标模式或关闭弹窗 | 过期结果不能覆盖当前表单；文字模式保留本机文字/Emoji |
| 在线壁纸启用/下一张/应用 | 成功保存启用状态后才请求；完整图片加载后更换背景并显示作者来源 |
| 加载图片期间选择其他背景 | 过期请求不能覆盖后选背景 |
| 暂停在线壁纸 | 停止新的图库请求，背景回到本地来源 |
| WebDAV 测试连接 | 只读取文件；404 提示确认目录存在，不提前声称有写入权限 |
| 手动首次同步至空位置 | 条件创建 JSON，上传后读回一致才显示成功 |
| 两台设备指向同一文件 | 内容不同时先选择版本；远端下载确认后才替换本机 |
| 两端同时改动/确认后又改动 | 重新比较，不静默覆盖旧版本 |
| 自动检查 | 建立手动基线且启用后，在页面可见且未编辑时检查；本机单端变化可上传，远端变化需确认 |
| 检查导出与远端 JSON | 包含桌面内容，不包含 WebDAV 用户名、密码或同步配置 |
| 暂停/清除 WebDAV | 不删除桌面或远端文件；清除移除本机连接信息 |

当前实现按整份桌面同步，不做字段级合并；关闭栖页页面后不后台同步。账号系统、高级工具和新增实时数据组件不属于本轮范围。
