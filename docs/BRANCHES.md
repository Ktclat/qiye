## 后续约定

一个需求或相关的一组修改最多保留一个必要开发分支。维护者将完成并通过验收的修改合入 `main`，由该版本构建 `gh-pages`，确认 Pages 和正式链接成功后删除临时分支。未通过验收的有效工作保持在明确的开发分支并注明阻塞事项，不发布半成品，不因清理要求直接删除。

发布检查至少包括 `npm test`、`python3 tests/browser-e2e.py`、构建一致性、备份兼容与数据保留、Pages 实际 HTTP 内容。新增文档或状态声明与检查记录同步，不能只推进分支名却遗漏主代码。
