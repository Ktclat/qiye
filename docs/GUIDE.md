## 功能一览

| 能力 | 当前实现 |
| --- | --- |
| 自由编排桌面 | 网站、文件夹和组件表面直接拖动；实时让位、松手保存、Esc 恢复、键盘排序、文件夹收纳与跨组移动 |
| 导航与头像 | 默认 50px 侧栏，宽度与透明度可调，支持左侧、右侧及顶部导航；自动隐藏、分组名称开关、本地头像 |
| 网站真实图标 | 按显示尺寸与屏幕像素比选择网站图标；SVG、高清位图、多候选选择、本机上传与文字回退 |
| 多尺寸卡片 | 网站、文件夹和内置组件支持 `1×1`、`1×2`、`2×1`、`2×2`、`4×2`；第三方组件以声明尺寸为准 |
| 搜索与收藏 | 五种内置引擎与自定义 `{q}` 模板；真实引擎图标、查找收藏、可选本机最近搜索 |
| 浏览器集成 | 按需授权书签导入与查找、历史查询；工具栏与右键菜单收藏网页或链接 |
| 时间与搜索框 | 分别设置显示、独立区域固定或随内容滚动、水平/垂直偏移；时间字号、字重与颜色，搜索框尺寸、圆角与透明度 |
| 主题与材质 | 浅色、深色、跟随系统；纯色、毛玻璃、亚克力及 Mica 风格；本地 Inter 字体、字号与主题色 |
| 壁纸 | 双栏壁纸中心、本地图片/视频、六款内置渐变、deepin、Wallhaven 精选、Picsum 与 Commons、模糊与暗度 |
| 数据 | 本机保存、JSON 导入导出、自有 WebDAV 同步、覆盖前的版本与冲突检查 |

### 导航、头像与桌面工具

点击导航中的栖页图标即可打开设置，图标下不显示品牌名称。在“设置 → 侧边栏”中，可选择左侧或右侧的侧边栏，也可改为顶部导航；支持调整侧栏宽度、导航透明度、分组名称显示，以及“始终显示 / 自动隐藏 / 收起”。自动隐藏支持鼠标移入与键盘聚焦；收起后可以通过边缘按钮展开。编辑桌面时，分组可沿导航方向拖动排序；平时滚轮默认只滚动分组列表，隐藏滚动条；可在“侧栏滚轮行为”中切换为滚轮切组。

头像支持本地 PNG、JPEG、WebP。选择图片后在本机居中裁切为 **256×256** 的静态方图，上传文件不超过 **4 MiB**，保存后的图像数据不超过 **256 KiB**。头像只是设置入口，不代表账号，也不上传到头像服务；它会随桌面 JSON 备份与 WebDAV 同步，可随时恢复栖页默认图标。

右上角的壁纸、编辑、添加、快捷键四个按钮可以在“设置 → 打开方式”选择**始终显示**或**自动隐藏**，也可以点击工具区的眼睛按钮切换。键盘图标在鼠标悬停或键盘聚焦时显示快捷键说明。壁纸按钮还可单独隐藏。

桌面网格默认不放置添加卡片，仍可通过右上角“＋”或桌面空白处的右键菜单添加内容。“设置 → 图标”可以重新开启网格添加按钮。内容区不重复当前分组名称，底部保留固定在窗口位置、可关闭的日常短句，不随卡片数量移动。

### 时间、搜索框与布局

默认比例参考紧凑的新标签页布局；用户可以调整字号、网格和偏好。

| 部位 | 新安装默认值 | 可调整内容 |
| --- | --- | --- |
| 侧边栏 | 宽 50px | 宽度 40–120px、透明度、位置与显示方式 |
| 时间 | 70px、400 字重 | 显示、30–160px 字号、200–700 字重、颜色、12/24 小时、秒数 |
| 日期 | 14px 基准字号 | 月日、星期、农历分别控制，随界面文字比例调整 |
| 搜索框 | 600×46px、23px 圆角 | 宽度、高度、圆角、透明度与显示开关 |
| 图标名称 | 12px | 名称字号、颜色与是否显示 |

“设置 → 时间 / 日期”的“滚动时固定时间”与“设置 → 搜索栏”的“滚动时固定搜索框”彼此独立，新安装默认都关闭。开启某项后，该区域放在独立固定区；内容在其下方单独滚动，不与顶部重叠。当前格式中已保存的偏好按设置生效。开启秒数后，秒与时、分同字号，字重和颜色也完全一致，使用普通 `HH:MM:SS` 分隔。

在“设置 → 布局”分别调整时间与搜索框的水平、垂直偏移。水平偏移以窗口宽度为基准，窄屏会限制在可见区域；垂直偏移调整排版间距；固定区域的高度按内容保留，较矮屏幕会限制偏移和时钟大小以保留桌面空间。可以一键恢复默认位置，也可以调整内容最大宽度、极简模式和分组切换动画。

网站与搜索结果的打开方式现在独立设置。可在“设置 → 打开方式”选择是否分别在新标签页打开，并决定是否记住上次分组。“设置 → 搜索栏”的**保存最近搜索默认关闭**；开启后只在当前浏览器保存最近 20 条，记录不进入 JSON 备份或 WebDAV，支持单独清除。

### 主题、字体与轻量材质

“设置 → 主题与材质”提供浅色、深色和跟随系统，桌面面板与 14 类组件共同响应主题，同时保留便签、倒数日等组件的色彩区别。侧栏、搜索框、文件夹和弹层使用一致的材质系统。

| 材质 | 显示方式 |
| --- | --- |
| 纯色（`solid`） | 清楚的色块表面，不使用背景模糊 |
| 毛玻璃（`glass`） | 半透明底色与柔和背景模糊，默认材质 |
| 亚克力（`acrylic`） | 在磨砂效果上增加细微纹理与层次 |
| Mica 风格（`mica`） | 柔和着色的轻量表面，不使用背景模糊 |

这里的 **Mica 风格是 CSS 实现的网页视觉效果，不是 Windows 原生 Mica 材质**。面板透明度与模糊强度可调，模糊默认 **14px**、上限 **24px**；侧栏与搜索框还可单独调整透明度。开启“减少视觉效果”会关闭面板模糊和过渡动画，改用更实的底色。不同设备与浏览器的实际负载仍有差异，不以特效数量或夸张的模糊作为设计目标。

默认随包提供 **Inter 可变字体**，用于数字、拉丁字母和标点；中文使用系统字体，也可以整体选择系统字体。Inter 字体文件约 **71.21 KiB**，采用 **SIL Open Font License 1.1**，运行时不请求外部字体服务。界面文字比例、时钟字号与字重、图标名称字号和颜色都可以调整。字体来源和完整许可见 [第三方素材说明](THIRD_PARTY.md)。

### 拖动与分组过渡

鼠标直接拖动卡片表面，组件内的输入框、按钮和文字编辑仍可正常使用。拖动过程中，邻近卡片用 FLIP 位移动画实时让位，松手后才保存；取消不会把预览顺序写入存储。没有附加的拖动手柄按钮。触屏设计为静止长按约 330ms 激活，短划动仍滚动，手感需真机验收。键盘聚焦卡片后 **Alt + 方向键** 调整顺序；`Esc` 取消。拖到文件夹中央收纳网站，拖到侧栏分组跨组移动；拖到另一个顶层网站中央停留约半秒，会创建包含两者的文件夹。文件夹内不再常驻“移出”按钮，右键 → 移动到仍可移回桌面。

切换分组时，卡片从下方向上轻滑入场，使用短暂错峰，减少整个网格同时突现的感觉。可以在布局中关闭该动画；“减少视觉效果”和系统减少动态效果设置同样会停用相关过渡。顶部导航超出可见宽度时，编辑分组的拖动支持左右边缘滚动；侧边栏仍沿纵向排序和滚动。

## 安装与更新

### Chrome / Edge 安装

1. 在 [Releases](https://github.com/Ktclat/qiye/releases) 下载 `qiye-X.Y.Z-chrome-edge.zip` 并解压；也可从 **main → Code → Download ZIP** 下载源码。
2. Chrome 在地址栏打开 `chrome://extensions/`；Edge 打开 `edge://extensions/`。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择**直接包含 `manifest.json` 的仓库根目录**，然后新建标签页。

使用扩展无需 Node.js、`npm install` 或构建。Manifest 声明的最低 Chrome 版本为 **116**；目前面向 Chrome / Edge，尚未适配 Firefox。扩展下载包与源码均使用“加载已解压的扩展程序”安装。

使用 Git 获取源码：

```sh
git clone https://github.com/Ktclat/qiye.git
cd qiye
```

保留安装目录，更新源码，再到扩展管理页点击“重新加载”。当前只接受 `schemaVersion: 5` 的完整数据，本机使用 `qiye.state.v5` 存储；不读取、迁移或删除旧存储键，首次使用当前格式会从默认桌面开始。旧格式 JSON / WebDAV 文件会被明确拒绝，不自动转换或覆盖。开发阶段允许破坏性调整，历史测试数据和备份不保证可用；需要重新配置时可在“备份与恢复”中重置桌面。

### 网页与扩展有什么区别？

| 项目 | 网页 / 独立 HTML | 扩展安装版 |
| --- | --- | --- |
| 桌面、搜索、组件与外观 | 支持 | 支持 |
| 替换浏览器新标签页 | 需自行打开页面 | 安装后由扩展接管 |
| 桌面存储 | 当前来源的 `localStorage` | `chrome.storage.local` |
| JSON 导入导出 | 支持 | 支持 |
| WebDAV | 服务须允许当前网页跨域访问（CORS） | 按需申请所填服务站点的访问权限 |
| 网站与搜索引擎图标 | 可显示站点图片；读取网页提取图标受 CORS 限制 | 主动提取时按站点请求访问权限，可使用浏览器图标回退 |
| 书签、历史、工具栏与右键收藏 | 无扩展接口 | 按功能使用或授权 |
| `Alt+C` 扩展快捷键 | 不支持 | 打开新的栖页本地搜索页 |

仓库内的 `Qiye-preview.html` 可直接打开，包含桌面所需的脚本和样式；联网功能仍需网络。公开网站、独立 HTML 与扩展各自保存数据，可通过 JSON 备份迁移，或配置同一份 WebDAV 文件同步。直接打开本地 HTML 时，持久化与跨域访问还受浏览器对本地文件的策略影响。

网页更换域名后，需要从原页面导出 JSON 并在新页面导入，或重新连接同一 WebDAV 文件；WebDAV 凭据需要在新页面重新填写。GitHub Pages 的发布配置与迁移步骤见 [部署指南](DEPLOYMENT.md)。

## 网站图标与智能提取

**编辑网站 → 获取图标 → 选择候选 → 保存**。候选只列原站声明、经核验的站点素材或常规路径上实际能加载的图片，本次编辑最多保留 48 个去重候选，不伪造高清。获取和预览不会修改已保存的网站。选中的 URL 或本机静态图片保存在该卡片的 `iconUrl` 中，随备份 / WebDAV 保留；其他卡片的自动优选缓存不会替换这一选择。关闭或取消编辑仍保留原图。

选择“文字图标”可修改文字和底色；“上传”支持 PNG、JPEG、WebP，先在本机裁切并重新编码，最大输入 4 MiB、保存图像数据最大 256 KiB。图片本身的白底仍保留，不自动抠除品牌白色部分。

**设计说明：[FAVICONS.md](FAVICONS.md)**。侧栏四格按钮是独立入口。自动补充高清图标默认开启，遇到低清或失败时才读取有限元数据，允许关闭；新增的首方来源目录、ICO 原生大帧与实际像素提示详见设计文档。

网站卡片默认选择“自动获取网站图标”。候选会结合声明格式、尺寸、实际加载尺寸、显示区域和屏幕像素比排序，优先选择可缩放 SVG 或足够清晰的位图。常规候选包括站点的 `/favicon.svg`、`/apple-touch-icon.png`、`/favicon.ico`；扩展版还会根据需要向浏览器请求合适尺寸的图标。图片成功加载后才显示，全部失败时保留原文字、Emoji 或内置图标。这里只使用网站自身或其声明的图片地址，不接入第三方 favicon 代理服务。

当一个图标已经显示但分辨率偏低时，页面会保留当前图片，并尝试最多 **3 个**更合适的候选；同一站点、同等或更小尺寸的自动升级需求有 **24 小时**冷却，避免每次重绘都重复探测。候选的真实尺寸会更新到本机缓存，低清晰度的旧缓存不会永久挡住更好的来源。站点只提供小图时仍可能不够清晰，算法不会虚构原图没有的细节。
在“新增网站”或“编辑网站”中，可以选择两种模式：

| 图标显示 | 行为 |
| --- | --- |
| 自动获取网站图标（`auto`） | 尝试网站真实图标，失败时使用下方的文字回退 |
| 使用文字 / Emoji（`text`） | 显示“文字 / Emoji 回退”和背景色，不为该卡片主动加载远端图标 |

需要查找更合适的图标时，填好网站地址、选择自动模式，再点击 **“获取图标”**。扩展会按需请求该网站的读取权限。提取器读取页面 HTML 中的 `rel="icon"`、`apple-touch-icon` 等声明，结合尺寸和格式选择候选；HTML 图标不足时，会读取页面声明的**同源 Web App Manifest** 并补充其中的 `icons`。它只解析元数据，不执行页面脚本或把抓取的 HTML 插入界面。按钮返回候选后仍需完成图片加载，候选提取成功不代表图片一定可用。

页面和清单读取保留地址路径，去掉查询参数与片段；仅处理公开域名的 HTTPS 地址，HTTP 网址会尝试 HTTPS。localhost、IP 地址、自定义端口或跨来源跳转不会被用于读取提取。**GitHub Pages 等网页版受目标站点的 CORS 策略限制**：不能读取 HTML 时会提示并回退到常规图标地址，图片本身仍可能正常显示。扩展拒绝站点权限、超时或遇到不支持的页面时也保留文字回退，可继续使用该网址。

已提取的候选与成功加载的图标地址在本机缓存 **7 天**，最多保存 **200 个页面**；提取失败暂避 **10 分钟**，图片加载失败在当前页面暂避 **5 分钟**。主动点击“获取图标”可以重新尝试。通常缓存的是地址与状态；ICO 大帧另以原生 PNG 在本机有限缓存（最多 16 张/约 2.4 MB），不进入备份。图标模式和原文字回退会随 JSON 备份 / WebDAV 同步，提取缓存不会同步；新设备可重新提取。

### 搜索引擎图标

搜索框中的引擎按钮、切换菜单与“设置 → 搜索栏”的引擎列表使用同一套图标加载、缓存和失败回退。内置及自定义引擎从搜索地址模板中取出网站来源，例如 `https://example.com/search?q={q}` 对应 `https://example.com/`。已知搜索子域（哔哩哔哩的 `https://search.bilibili.com`）使用对应主站 `https://www.bilibili.com/`，其他来源保留原子域；显示或提取图标不会提交搜索词，也不会请求搜索结果页。

在搜索设置列表中点击引擎旁的 **“提取图标”**，可以主动读取该站点首页的图标声明。扩展按需申请相应站点权限，网页版受该站点 CORS 限制；失败时保留常规图标候选和引擎文字回退。搜索模板仍保存在桌面设置中，提取的图标地址只进入本机缓存。

引擎图标在浅色与深色主题下都取消了人为添加的白底与白边，保留图标本身的形状和比例。如果网站提供的图片自带白色背景，它仍可能显示底色；栖页不会强行抠图或裁掉标志的一部分。

## WebDAV 同步

不需要栖页账号。栖页直接连接你提供的 WebDAV 服务，将整份桌面保存为一个 JSON 文件；多台设备使用相同目录和文件名即可比较与同步。

### 配置步骤

打开“设置 → WebDAV 同步”，填写以下内容。地址仅为格式示例，请替换为自己的服务。

| 字段 | 示例 / 要求 |
| --- | --- |
| WebDAV 目录地址 | `https://dav.example.com/qiye/`，必须是**已经存在的目录** |
| 用户名 | WebDAV 服务提供的用户名 |
| 密码 / 应用密码 | 服务对应的凭据；已保存后留空会保留原密码 |
| 同步文件 | 默认 `qiye.json`；相对于上述目录，文件名须以 `.json` 结尾 |

1. 可先点击“测试连接”。测试只读取文件，不保存配置、不创建文件，也不验证写入权限；`404` 仍需确认父目录存在。
2. 点击“保存并启用”。扩展会按需请求该服务站点的访问权限。
3. 点击“立即同步”。空位置在首次手动同步时尝试创建文件；已有不同桌面会先显示版本选择。
4. 根据比较结果选择“保留本机”或“使用远端”。确认前可分别导出本机与远端副本；后者会替换本机桌面。

栖页不会自动创建目录。连接使用 HTTPS，仅 `localhost` / `127.0.0.1` 允许 HTTP；请填写服务的最终目录地址，客户端拒绝重定向。

### 自动检查与冲突处理

完成一次手动同步后，可开启“自动检查同步”。它只在栖页**打开、可见且空闲**时检查：本机单端修改可自动上传，远端更新或双端修改需要确认。关闭栖页后不执行后台同步。

同步按整份桌面处理，不逐字段合并。首次发现不同远端、双端都修改、远端被删除，或用户确认期间任一版本变化时，会重新比较或请求确认；旧确认不能静默覆盖新数据。

服务需要支持 HTTP 条件写入：创建使用 `If-None-Match: *`，覆盖已有文件使用强 `ETag` 与 `If-Match`，上传后还会读回校验。**已有文件缺少强 ETag 时仍可下载，但不能覆盖上传**；弱 ETag（以 `W/` 开头）不能用于这里的版本保护。

### 网页版的 CORS 要求

若从公开演示或其他网页连接，WebDAV 服务需要允许相应网页来源跨域访问：

| 配置项 | 要求 |
| --- | --- |
| 允许来源 | GitHub Pages 使用 `https://ktclat.github.io`，来源中不包含 `/qiye/` 路径；其他部署使用对应网页来源 |
| 允许方法 | `GET`、`PUT`、`OPTIONS` |
| 允许请求头 | `Authorization`、`Content-Type`、`If-Match`、`If-None-Match` |
| 暴露响应头 | `Access-Control-Expose-Headers: ETag` |

具体配置取决于你的服务及反向代理。服务不支持网页跨域访问时，可使用扩展安装版；强 ETag 与条件写入要求仍然适用。当前尚未完成具体服务商的账户联调，因此不承诺某一服务即配即用。

## 壁纸与数据隐私

### 在线壁纸

点击“发现壁纸”小组件或工具栏壁纸图标，打开同一个左右布局的壁纸中心。左栏为自定义背景、官方背景、deepin、Wallhaven、Picsum、Wikimedia Commons；“壁纸参数”固定在左栏最下方。右栏显示相应图片、署名和操作。

联网默认关闭，选择在线图库后需主动启用；Picsum 免密钥，Commons 只展示识别到许可的图片并保留作者、文件页和许可链接。Deepin 和 Wallhaven 提供带版本/日期的可信精选清单，图片从原站直接加载；Wallhaven 并非统一商用许可。不能直接浏览的外链栏目已删除。官方背景是本项目六款内置渐变，不是 iTab 的私有壁纸库。

列表按需分页、有限缓存；切换来源或关闭弹窗会取消旧请求。完整图片加载成功后才应用，失败或请求过期保留原背景。恢复本地背景/停用在线图库在“壁纸参数”中操作；“每日轮换内置背景”只轮换内置渐变。缓存周期、授权与接入边界见 [壁纸中心文档](WALLPAPERS.md)。

### 数据保存与权限

桌面、网址、便签、待办、头像和设置默认保存在本机。栖页没有账号服务器、广告脚本或行为遥测，也不从 CDN 加载运行脚本或字体。头像在本机处理，不发送到头像服务；Inter 字体随包提供。网站卡片和搜索引擎会向对应站点或该站点声明的图片 CDN 加载图标；引擎图标请求不携带输入的搜索词。在线壁纸、天气与 WebDAV 在对应功能启用或用户操作后访问外部服务。搜索提交与网址点击会访问所选网站。

WebDAV 地址、用户名、密码及同步基线单独保存在本机，**不包含在 JSON 导出或远端同步文件中**。本机凭据未另行加密；远端桌面是普通 JSON，**未提供端到端加密**，应保存到自己的私有目录。同步内容会包含便签、网址等个人桌面数据，以及头像和所选本地壁纸素材。最近搜索记录独立保存在当前浏览器，默认不记录；开启后最多保存 20 条，不包含在桌面备份或同步文件中。

| 项目 | 说明 |
| --- | --- |
| 基础权限 | `storage` 保存数据；`activeTab`、`contextMenus` 用于主动收藏页面或链接；`favicon` 用于浏览器图标回退 |
| 可选权限 | 书签、历史按需授权；WebDAV 按所填来源申请访问权限；智能提取按目标站点申请访问权限 |
| 图片权限 | Picsum 使用固定站点权限，功能默认关闭 |
| 天气 | 主动开启后发送所选城市经纬度，不读取设备精确定位 |
| 大小限制 | 本地壁纸图片/视频最大 **4 MiB**；头像输入最大 **4 MiB**，保存图像最大 **256 KiB**；JSON 备份最大 **6 MiB**，网页还受存储配额限制 |

“暂停同步”保留配置和数据；“清除本机连接”只删除当前浏览器中的 WebDAV 配置与同步记录，保留桌面及远端文件。重置桌面不会直接删除远端文件，但启用的自动同步会继续同步桌面变化。更多说明见 [PRIVACY.md](PRIVACY.md)。

## 快捷操作

| 操作 | 效果 |
| --- | --- |
| `/` | 聚焦主搜索框 |
| 搜索框内 `Tab` / `Shift+Tab` | 向后 / 向前切换搜索引擎 |
| `Ctrl+K` / `⌘K`，或 `Ctrl+F` / `⌘F` | 在栖页内打开本地查找 |
| `E` | 切换桌面编辑模式 |
| `Esc` | 取消正在进行的拖动；通常用于关闭菜单/弹层，或退出编辑与极简模式 |
