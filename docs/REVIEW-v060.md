# v0.6.0 日历与备忘录界面审阅

参考：用户提供的六张 iTab 截图，涵盖宽日历卡片、日历主界面、日期差、工作日、节日时间线与备忘录左右布局。

## 修复与重构

| 发现 | 结果 |
| --- | --- |
| 默认图标仍统一圆角并增加自适应背景 | 默认 `iconShape: original`、`iconBackdrop: none`；原图不裁切、不额外补色 |
| 日历和备忘录套用通用窗口标题与表单样式 | 独立应用视图和 CSS，仅共用原生 dialog 的焦点、关闭与缩放基础设施 |
| 日历卡片纵向布局，缺少醒目的当天日期 | 默认 4×2 左日期 / 右月历，红色周末及今日圆点，保留 2×2 选项 |
| 日期工具藏在详情折叠区 | 顶部日历 / 工具标签；日期差、日期加减、工作日和年度节日时间线 |
| 农历和节日信息不完整 | 固定离线历法引擎，增加节气、传统节日及黄历；独立维护法定调休数据 |
| 备忘录编辑区被通用表单边框占据 | 贯穿窗口的侧栏与正文，顶栏操作、底部编辑 / 创建时间及自动保存状态 |
| 专用界面需要可控缩放和键盘路径 | 支持最大化 / 还原、既有窗口缩放、方向键切换日历标签与日期，手机备忘录切换列表 |

## 维护边界

视图、交互、日期模型、上游算法和草稿保存分别维护；旧通用日历 / 备忘录模板与样式已经移除，不叠加第二套兼容实现。当前持久化模型没有变化，不读取旧 schema、不增加迁移。已有用户主动保存的外观设置继续作为当前设置使用。

历法来源与完整许可见 [THIRD_PARTY.md](THIRD_PARTY.md)。工作日间隔采用 `(开始日, 结束日]`，同一天为 0；日期差使用本地民用日期，避免夏令时产生 23 / 25 小时误差。调休只覆盖已核实的 2026 年，节日时间线不代表法定假期。英文界面使用本地化节日、生肖、星座及黄历词汇；物候位置显示对应英文节气。

保留备忘录的延迟写入合并、失败草稿、重试、导出和关闭等待，不因样式重做而更换保存协议。没有接入 iTab 私有服务或复制其源码、图标资源。

## 验证

完整命令与实际结果记录在 [QA.md](QA.md)。新增逻辑用例覆盖新默认值、截图参考日期的农历、闰月、24 节气、年度可移动节日、语言缓存隔离、日期加减边界及周末标记。浏览器用例覆盖专用窗口、工具实时计算、最大化、节日跳转、键盘标签、手机列表，以及原有保存失败恢复和中英文路径。源模块、单文件网页、解压扩展使用同一份实现。
