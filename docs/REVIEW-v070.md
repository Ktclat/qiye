# v0.7.0 交互与组件审阅

日期：2026-10-14。参考用户给出的 iTab 添加面板、菜单、日历与备忘录截图，保持栖页独立实现和现有菜单命令。本轮没有引入历史兼容层。

## 发现与处理

| 问题 | 处理 |
| --- | --- |
| 鼠标没有长按启动，组件按钮被直接排除 | 增加 320 ms 长按；按钮短按保留原动作，拖动后抑制点击。输入编辑、触屏滚动、取消与键盘排序保留 |
| 计时器可能在移动起拖后再次启动 | 起拖立即清理长按计时器；增加单次拖动、取消与实际落位回归 |
| 拖动预览给组件错误预留标签高度 | 组件影像与原卡片等高，起拖与让位添加轻微动画；尊重减少动态效果设置 |
| 尺寸规则散落、全部组件只支持 2×2 / 4×2 | `widget-sizes.js` 统一五种尺寸；内置全部支持，外部至少支持 1×1 / 2×2 |
| 直接把完整表单缩到小格会裁切交互 | 紧凑尺寸由宿主提供摘要入口，点击打开完整实例；计时、天气与内容摘要继续刷新 |
| 日历过大，窗口缩放与大小混在一起 | 默认日历 1060 × 690；独立的 75%–125% 窗口大小，保留 75%–150% 控件缩放与最大化 |
| 设置只有居中窗口 | 新增右侧面板；打开时锁定本次呈现模式，切换分类不提前应用，下次打开按偏好生效 |
| 添加目录缺少预览与目标分组 | 独立 `widget-catalog.js`：左侧分类、大卡片预览、组合筛选、网站导航、尺寸与目标分组；不支持的尺寸禁用添加 |
| 关闭目录后预览控件仍留在隐藏 DOM | 关闭时清理内容和挂载，避免隐藏控件干扰后续操作；防止旧 close 事件清理刚打开的窗口 |
| 单文件构建器未支持命名导入别名 | 正确转换别名为对象解构；添加生成脚本语法检查，并在单文件上重复完整交互回归 |

默认图标本体 60 px，网格单格 84 px，间距 24 px；2×2 为 192 × 192，4×2 为 408 × 192。参数是按照参考截图调整的栖页实现，没有读取 iTab 内部布局配置。图标原始轮廓 / 透明背景继续作为默认。

## 接口与维护

组件 API 升到 v2；定义、校验、目录和尺寸菜单共享声明。`render` 接收呈现尺寸，生命周期上下文提供 `size`、`openSettings()` 和 `openDetail()`；摘要入口和目录预览不挂载扩展代码。完整详情关闭时清理事件和计时器，同一实例的配置和数据继续通过既有保存队列维护。

设置新增 `windowSize`、`settingsPresentation`；当前数据使用 schema 4 / `qiye.state.v4`，不迁移旧格式。新增界面文本同步提供英语，网页与扩展共用模块和样式。

[组件开发指南](WIDGETS.md) 补齐尺寸、拖拽、详情、无副作用预览、提交材料和验收要求。未来组件市场尚未上线；当前第三方组件通过源码审阅后随程序打包。

## 验证

308 项 Node 检查、3 项 Python 发布检查。浏览器包含 176 项桌面 / 编辑器、34 项组件接口、81 项日常组件源码、81 项日常组件单文件、44 项新交互源码、44 项新交互单文件，以及 7 项实际解压扩展检查。合计 467 项浏览器 / 扩展检查。源码与独立 HTML 的新交互用例覆盖全部 14 种组件、5 种尺寸、长按按钮启动与提交、取消不误触、窗口偏好应用时机、目标分组和完整详情中的编辑保存。

截图检查了日历、目录、侧栏、菜单、紧凑卡片和深浅 / 窄屏布局。发布后另用临时浏览器访问实际网页校验文件摘要、版本、语言、组件和持久化；远程运行结果见对应版本 GitHub Actions。详见 [QA.md](QA.md)。
